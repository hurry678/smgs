# 问题三 v2 建模与验收方案

## 1. 目标与边界

问题三要求对附件4的 20 条样本输出情感极性、情感强度、主要参考模态、
模态作用程度和局部关键证据。v2 不重新训练预测器，直接使用问题二已定稿的
`M3-ensemble9 + C2`。解释对象始终是该冻结预测器的真实输出。

数据边界如下：

- 模型权重、归一化统计量和 C2 发布规则全部冻结；
- 解释参数只在附件2验证集 728 条样本上选择；
- 参数冻结后才读取附件4；
- 官方 test、附件3和附件4都不能反向影响参数选择；
- “贡献”“作用”均指相对于固定遮挡基线的模型归因，不表述为物理因果。

## 2. 旧实现审计结论

旧代码存储联盟的顺序是

```text
(), T, A, V, T+A, T+V, A+V, T+A+V
```

但 Shapley 函数把列号解释为三位二进制掩码。正确位掩码顺序应为

```text
(), T, A, T+A, V, T+V, A+V, T+A+V
```

因此旧数组第 3、4 列，即 `V` 与 `T+A`，在计算时被互换。Shapley 效率
加和只检查三项之和等于全集与空集之差，无法发现联盟语义错位。v2 同时用
联盟顺序断言和解析函数测试封闭这一漏洞。

旧方案还有四类解释风险：

1. 主要模态混合分类绝对份额与强度绝对份额，可能把抑制预测类别的模态称为
   “主要参考模态”。
2. Negative 样本的强度方向未翻转，局部证据排序语义相反。
3. 用原始遮挡效应和 top-1 集中度比较 `w=3/5/10`，天然偏向删除预算更大的
   窗口。
4. 音视频位置按字符比例映射，未利用可获得的原视频和 MFA 资源。

## 3. 冻结预测器

对模型成员 \(k=1,\ldots,9\)，设三分类概率为 \(p_k(y\mid x)\)，原始强度为
\(r_k(x)\)。集成输出为

\[
\bar p(y\mid x)=\frac{1}{9}\sum_{k=1}^{9}p_k(y\mid x),\qquad
\bar r(x)=\frac{1}{9}\sum_{k=1}^{9}r_k(x).
\]

类别解释目标固定为发布类别 \(\hat y\) 的对数平均概率

\[
f_c(x)=\log \bar p(\hat y\mid x),
\]

强度解释目标为 \(f_r(x)=\bar r(x)\)。使用对数概率可保持不同样本间的尺度
可比性，又不改变同一样本上的类别排序。

## 4. 模态级精确 Shapley

玩家集合为 \(N=\{T,A,V\}\)。对任意联盟 \(S\subseteq N\)，保留 \(S\)
中的模态观测掩码，其余模态置为不可观测，重算冻结模型。三模态仅有 8 个
联盟，可直接精确计算：

\[
\phi_i(f)=\sum_{S\subseteq N\setminus\{i\}}
\frac{|S|!(3-|S|-1)!}{3!}
\left[f(S\cup\{i\})-f(S)\right].
\]

分类与强度分别计算 \(\phi_i(f_c)\) 和 \(\phi_i(f_r)\)。每条样本必须满足

\[
\left|\sum_i\phi_i(f)-[f(N)-f(\varnothing)]\right|\le 10^{-5}.
\]

同时输出 LOO 效应

\[
\mathrm{LOO}_i=f(N)-f(N\setminus\{i\})
\]

作为诊断，不以 LOO 替代 Shapley。

对模态对 \(i,j\) 还计算 Shapley 两两交互。以剩余模态 \(k\) 为例：

\[
I_{ij}=\frac{1}{2}\left[
f(ij)-f(i)-f(j)+f(\varnothing)
+f(ijk)-f(ik)-f(jk)+f(k)
\right].
\]

## 5. 主要参考模态与作用程度

`primary_modality` 表示对当前预测类别的主要支持来源：

1. 若至少一个分类 Shapley 为正，取最大正贡献；
2. 若全部非正，取最大绝对分类贡献作为回退，并令
   `support_modality=null`；
3. `strongest_modality` 始终表示最大绝对分类影响，允许它是抑制作用。

这样把“支持预测”与“影响最大”分开，避免概念混用。

用于展示的模态作用程度仍保留分类与强度绝对份额的等权平均：

\[
e_i=\frac{1}{2}
\frac{|\phi_i(f_c)|}{\sum_j|\phi_j(f_c)|}
+\frac{1}{2}
\frac{|\phi_i(f_r)|}{\sum_j|\phi_j(f_r)|}.
\]

它只表示综合影响大小，不用于决定主要参考模态。

## 6. 局部证据

在每个模态的有效位置序列上，以窗口 \(w\) 和步长 \(w\) 执行连续遮挡。对
每个连续窗口构造两个同预算控制：

- 随机连续窗口；
- 随机点散位置。

类别贡献定义为

\[
\Delta_c=f_c(x)-f_c(x_{\setminus W}).
\]

\(\Delta_c>0\) 才是支持当前预测类别的证据，\(\Delta_c<0\) 单独作为反证。

强度贡献按发布类别定向：

- Positive：\(\Delta_r=r(x)-r(x_{\setminus W})\)；
- Negative：\(-\Delta_r\)；
- Neutral：\(|r(x_{\setminus W})|-|r(x)|\)。

支持证据的排序分数为

\[
s=0.7\,\mathrm{PctRank}(\Delta_c)
+0.3\,\mathrm{PctRank}(\Delta_r^{\mathrm{dir}}).
\]

这保证 Negative 样本不会沿错误的强度方向排序。

## 7. 窗口尺度选择

候选尺度固定为 \(w\in\{3,5,10\}\)，在完整验证集 728 条样本上运行。
每个样本、每个模态取分类贡献最大的连续窗口，并除以实际遮挡位置数，得到
单位预算的 top-support 分数。

连续窗口与两类匹配控制的差值按 `video_id` 聚类重采样 5000 次。只有当
对两类控制的 95% CI 下界都大于 0 时，候选才进入选择集合；在合格候选中
取单位预算分数最高者。若没有候选通过双重门槛，则使用预注册中尺度
`window_size=stride=5`。附件4不参与该选择。

窗口级普通 bootstrap 和符号检验仅作诊断，不作为冻结依据，因为同一视频
内的多个窗口并非独立观测。

## 8. 原始证据回映

### 8.1 文本

使用冻结 MiniLM 对应的官方 fast tokenizer 重新生成 `offset_mapping`，并逐
元素校验 `input_ids`、`attention_mask` 和 `token_type_ids` 与存储张量完全
一致。文本证据必须满足

```text
text_snippet == raw_text[text_char_start:text_char_end]
```

### 8.2 语音与视觉

附件4原视频先用 ffmpeg 提取 16 kHz 单声道 PCM，再使用 MFA 3.4.1、
固定词典、声学模型与 G2P 模型做词级强制对齐。MFA 词通过原始字符区间与
BERT token offset 求交，得到语音起止时刻；视觉帧由实测 FPS 换算。

状态定义：

- `forced_alignment`：MFA 词时间映射；
- `approximate`：该样本 MFA 失败后的字符比例回退；
- `relative_only`：只允许出现在无原视频元数据的验证集解释中，最终附件4
  打包禁止该状态。

比例回退必须带警告，且不伪称“动态规划对齐”。最终 MFA 样本覆盖率不得低于
80%，否则停止发布。

## 9. 验收

必须同时满足：

- Q2 冻结清单、版本清单、9 个 checkpoint、MiniLM 和 Q2 数据哈希一致；
- 16 项以上本地协议与数学测试通过，Ruff 和 `py_compile` 通过；
- 三个窗口报告覆盖相同的 728 条验证样本；
- Shapley 加和误差不超过 \(10^{-5}\)；
- 冻结文件生成后才读取附件4；
- 附件4 20 个 ID 唯一且全覆盖；
- 每条文本证据精确回映；
- 每条音视频证据具有合法时段，视觉证据具有合法帧区间；
- 主要模态、支持模态、反证符号和交互字段通过独立打包校验；
- 最终清单无绝对路径，提交目录小于 50 MB；
- `ds/` 与 `优化/q2yhv2_1/` 相对 Git HEAD 无差异。

## 10. 论文结论边界

服务器结果回传前不能填写附件4预测分布、主模态计数、窗口选择结果或 MFA
成功率。最终论文可以声称“精确模型归因”“验证集忠实性比较”和“MFA 辅助
定位”，但不能声称：

- Shapley 证明了现实世界因果关系；
- 自动强制对齐等于人工时间标注；
- 附件4无标签条件下获得了 Accuracy、F1、MAE 或 Pearson；
- 未通过聚类置信区间门槛的局部方法具有普遍显著优势。
