# 模型、求解算法与旧版取舍

## 1. 对拟议方案的判断

“二进制缺失掩码＋注意力融合＋交叉熵和均方误差双任务”是合理基线，但不足以单凭结构名称构成创新结论。
主要需要补足：padding与缺失的分离、连续缺失跨度、缺失前的文本编码、损失尺度平衡、
分类/强度输出一致性，以及独立的缺失验证协议。

附件3无标签，因此只能完成推理、格式验证和输入扰动一致性检查；
分类准确率、Macro-F1、MAE、Pearson和缺失规律须在有标签的附件2验证集测量。
从注意力权重不能直接推出因果解释；问题三还需要独立归因和遮挡忠实性证据。

## 2. ds已有结果值得继承什么

权威入口：`../ds/artifacts/q2/v3_m3_ensemble9/version_manifest.json`；
模型实现：`../ds/scripts/q2_models.py`；训练：`../ds/scripts/q2_train.py`；
统一验证：`../ds/artifacts/q2/robustness_analysis_fixed5/`。本节数值为已有结果，不是本轮新实验。

| 旧版证据 | 收益与本轮取舍 |
|---|---|
| 独立训练种子和固定评价掩码；7种非空缺失子集×3比例×5复本 | 继承固定评价库、按样本ID稳定生成、保存掩码SHA |
| BiGRU＋模态门控＋时间池化 | 保留为主要实用对照，结构简单且可复核 |
| M0连续缺失描述 `q_t` | 继承思路；重新定义有效域，排除padding造成的假长缺失段 |
| 三种子 M0 `R_MAE=0.624765±0.022579`，B4 `0.626377±0.016703` | 收益仅0.001612且不稳定；不能预设结构掩码一定提升 |
| M3九模型集成 `R_MAE=0.604523`，完整Macro-F1 `0.599707` | 可参考降方差思路；必须区分单模型与九模型预算，不能归为新结构收益 |
| M2在单种子 `R_MAE=0.620249`，不及旧M0的0.610839 | 注意力可能增加估计方差；本轮仅作候选，不堆层数 |
| 保留失败实验和原始/发布结果 | 继承，禁止只汇报胜者或最好种子 |

需修正的具体问题：

1. 旧报告把问题二的音视频称为“由问题一处理流程生成”。实际来自附件2的74/35维特征；
   本地问题一的16/6维自提取特征不能混入附件2训练接口。题目规定问题二参数在附件2 train学习。
2. 旧M0 `structure()`在固定50位置上计算缺失段，缺少独立的padding域，
   因而尾部padding可能进入最长缺失段、观测率、片段数。新协议必须修正。
3. 旧 `make_missing()`在非零位置列表上选片段，可能跳过自然缺失孔洞；
   本轮在原始序列索引中选真实连续窗口，记录实际新删除数量。
4. 旧文本 `[CLS]/[SEP]`进入融合观测掩码；本轮只允许其辅助编码，不参与三模态融合和缺失比例分母。
5. 旧“冻结BERT”仅禁止梯度；`model.train()`仍会激活编码器dropout。本轮冻结编码器始终 `eval()`，
   缓存键包含编码器SHA、输入ID、原始attention、合成掩码和token type。
6. 旧包声明未包含服务器模型权重。九个融合头加MiniLM不能仅凭CSV认定满足50MB，
   必须检查完整依赖权重；本轮提供约17.74MB的小BERT作为可交付默认。
7. 旧集成的21条件置信区间/符号检验把共享样本的条件当重复单位；只能描述该矩阵，
   不能据此宣称独立统计显著。本轮保留逐视频配对预测再重采样。
8. 旧6模型主指标0.604131小于9模型0.604523，最终又选9模型。多目标折中可以成立，
   但容差与优先级须提前冻结，本轮不事后改评分公式。
9. 旧过程文档前后包含M0和M3两版不同提交；仅用版本清单辨识历史。不能复制正文中的旧路径后误发布。
10. 旧test已有M0/M3结果，已经不再是对本项目完全盲的测试集。
    新版本只能冻结后追加一次描述性审计，不能靠“换run_id”重新获得未见测试的独立性。

## 3. 统一数学接口

aligned序列最多50位置。设有效时序域为 `D_it`，原始可观测状态为 `O_itm`，
合成保留状态为 `S_itm`，最终可见掩码为：

`M_itm = D_it · O_itm · S_itm`。

`D=0`是padding/特殊位置；`D=1,M=0`是有效域中的不可用信息。由原始float32数值先确定掩码，
再标准化。单维合法0不等于缺失；题给音视频在有效域内全维0作为不可观测接口状态。
文本UNK=100是未知词元，不自动等同“已知缺失”，详见数据协议。

文本模型固定为 `google/bert_uncased_L-2_H-128_A-2`。把缺失位置ID替换为103，
编码器attention置0，随后重新计算所有剩余位置的上下文表示。禁止先编码完整文本再把隐藏向量清零，
禁止从raw_text或另一特征版本恢复测试缺失内容。

统一投影到 `d=64`，BiGRU每方向32（总64），一层，dropout=0.15。
在有效域内可用零输入推进GRU的时间状态，借相邻观测建模；pad必须用长度打包或按真实域裁剪，
不能让双向GRU从尾部padding读入信号。缺失位置隐藏态在作为观测key/value与池化时再次置零。

### 候选结构

| ID | 模型 | 目的/主要限制 | 优先级 |
|---|---|---|---|
| B0 | train类别先验＋train强度中位数 | 无信息下界；统计常量不依赖valid/test | P0 |
| B1 | 冻结小BERT＋语义位置masked mean＋线性双头 | 文本基线，量化多模态是否真正贡献 | P1 |
| B2 | 三模态投影＋各自masked mean＋拼接MLP双头 | 可部署简单基线，不用跨模态注意力 | P0 |
| B3 | 三模态BiGRU＋内容动态模态门控＋时间池化 | 容量匹配对照：保留硬掩码，无显式掩码侧通道 | P1 |
| M1 | B3＋3维二进制掩码侧通道 | 用户方案的最小实现；检验“知道缺什么”的增益 | P0 |
| M2 | M1＋padding安全连续缺失结构 | 主推荐候选；检验“缺在哪里、缺多久”的额外价值 | P1 |
| M3 | M2＋一层局部跨时刻多头注意力 | 检验同一位置不可用时能否利用邻近模态证据；易过拟合 | P1 |
| M4 | 最优单模型＋完整视图教师的一致性蒸馏 | 训练策略候选，不宣称独立网络架构；不能保证恢复真实丢失情感 | P2 |
| M5 | 三个单模态专家＋按覆盖率门控的后融合 | 避免局部同位置交互过强；全模态缺失走先验 | P2 |

M1/M2的模态融合为：

`a_itm = f_gate([h_itm ; q_it])`

`w_itm = M_itm exp(a_itm) / sum_k M_itk exp(a_itk)`

`z_it = sum_m w_itm h_itm`。

分母为0时所有 `w=0,z=0`。时间池化只对 `D=1`且至少一个模态可观测的位置归一化。
整条样本没有语义观测时输出训练先验并标记 `no_evidence_fallback`，不能softmax全−inf或删样本。

M1的 `q=[M_text,M_audio,M_vision]`。M2在每模态定义六项：
可见标志、有效域内5位置窗口观测率、当前缺失段总长度/L、到左/右最近观测距离/L、
有效域观测率；再拼3模态可见状态one-hot（8类含空集），合计 `6×3+8=26`维。
没有某方向观测时距离=1；padding所有统计=0；二进制3维已包含在26维中，不重复拼接。

M3的query来自有效观测的 `(t,m)`，key/value仅来自其他模态且 `|t-s|≤5`的有效观测；
4头、一层、残差＋LayerNorm，key集合为空则该query的attention增量=0。
该模块真正跨时刻；旧ds所谓cross-time实现在每个t上仅做三模态attention，不能混称。
缺失处不作为“观测query”；本候选融合剩余证据，不声称生成了真实缺失特征。

M4用仅由train训练并冻结的完整视图教师，加入
`λ_KD τ² KL(stopgrad(p_teacher^τ) || p_student^τ) + λ_regKD Huber(r_student-r_teacher)`；
教师只看该train样本完整视图，student只看遮挡视图。τ=2，两个λ初值0.1；
严重缺失下教师可能教入不可辨识信息，必须做蒸馏去除与高缺失条件对照，不能强迫所有预测不变。

M5对缺失模态专家赋权0，剩余专家概率混合；强度按同一可见专家权重平均。
需要报告是否仅复制文本专家，三模态子模型只在train训练。

机制对照使用相同编码器、数据、缺失库、训练步数、损失和发布策略。
B3与M1/M2侧通道参数差异较大时增设等参数B3控制（总可训练参数差≤10%）；
统一主表记录全部参数、训练参数、计算量及权重体积，不能只列融合层。

## 4. 双任务目标与改进选项

基本头：`p=softmax(W_c z+b_c)`，`r_raw=3 tanh(W_r z+b_r)`。
三分类标签为Negative=0、Neutral=1、Positive=2，连续标签保持原float32，
不将近零值人工改成0。

`L_task = L_CE + λ_r L_reg`，
`L = 0.5 L_task(x,M_original) + 0.5 L_task(x,M_synthetic)`。

保留用户原案 `CE+MSE` 作为严格基线 `L0`；推荐比较：

- `L0`：普通CE＋MSE，`λ_r=1`。MSE强调强情感和离群样本，与MAE选型不完全一致。
- `L1`：普通CE＋SmoothL1(beta=0.5)，`λ_r∈{0.5,1,2}`。主候选，降低极端残差支配；
  不把beta=0.5写成已证明最优。架构筛选固定λ=1；权重搜索后置。
- `L2`：train频次平方根逆权重CE（均值归一化）＋L1选定回归损失。
  不同时上加权采样和全逆频权重，避免过补偿。
- `L3`：L1＋0.05一致性惩罚。真实正类加`relu(0.05-r_raw)`，负类
  `relu(0.05+r_raw)`，中性加`abs(r_raw)`；这是按真实标签定义的辅助约束，不能对argmax投影反传。
- `L4`：类别条件强度头，`r_neg=-3 sigmoid(u_neg)`、`r_neu=0`、
  `r_pos=3 sigmoid(u_pos)`，发布强度取预测类别对应分量。train按真实类别监督强度，
  必须同时报告软混合期望与硬发布误差，谨防分类错导致回归放大。P2。

分类与强度是同一标签的两种表达，存在辅助学习价值但不是两份独立监督证据。
记录共享层分类/回归梯度范数和余弦；只有观察到冲突且PCGrad改善验证结果，
才可把收益解释为缓解任务冲突。不能把MAE、Pearson之外的训练loss当最终竞赛成绩。

### 发布口径

P0固定使用ds的C2作为可比部署基线：argmax分类；中性强度0，正类
`max(clip(r_raw,-3,3),1e-4)`，负类`min(clip(r_raw,-3,3),-1e-4)`。
该规则会改写回归结果，故raw与published的MAE/Pearson必须双报，同时报告符号冲突率、
投影幅度和每类支持数。

P1最多追加一次valid上的预注册粗网格C3阈值对照：
负阈值{-0.5,-0.3,-0.1}×正阈值{0.1,0.3,0.5}，仍按冻结选择规则评价分类和发布强度。
不得根据附件3分布定阈值；没有校准预算时保持C2。导出前冻结 `publish_policy.json`，
序列化小数六位后检查正负号与中性0。

## 5. 优化算法：有条件比较

| ID | 求解方法 | 建议配置 | 额外成本与适用性 |
|---|---|---|---|
| O1 | 官方torch.optim.AdamW＋线性warmup＋cosine | lr=1e-3，wd=1e-4，warmup10%，min_lr=1e-5 | 稳定默认；Norm和bias不做weight decay |
| O2 | SGD＋Nesterov＋cosine | lr∈{0.01,0.03}，momentum=0.9，wd=1e-4 | 对照自适应优化器；可能需要更久收敛 |
| O3 | SAM包裹AdamW | rho∈{0.02,0.05}，lr=5e-4 | 双次前后向；小数据泛化候选，非保证改善 |
| O4 | PCGrad＋AdamW | O1参数；仅共享层投影 | 针对CE/回归负梯度内积；任务头保留本任务梯度 |
| O5 | GradNorm＋AdamW | α=1.5，任务权重lr=1e-3，正权重归一和=2 | 动态平衡梯度幅度；P2，先于复杂多目标组合 |

EMA（decay=0.99，每次优化器step之后更新）单列为权重平均实验，不称作新的优化器。
最终可比较预先指定的前三个训练种子等权概率/强度集成，禁止按test挑成员，
共享文本编码器一份；小于容差时优先单模型。

SAM每次两个pass必须使用同一batch、同一合成掩码和相同随机dropout状态；
冻结BERT恒eval。第二次反向前清梯度；恢复原参数后AdamW step；
非有限梯度则回滚扰动并记录，AMP需先正确unscale。先在FP32验证，不能默默变为普通AdamW。
PCGrad若`g_c·g_r<0`，用对方原始梯度把共享层梯度投影到其法平面，
两任务投影后取平均；无冲突直接平均，与不投影对照保持尺度一致。
GradNorm初始loss仅取train校准batch，权重保持正且不利用valid梯度。

先用O1比较模型，再仅在前两种结构上比较O2/O3/O4；不做模型×优化器×loss的全面穷举。
如需性能相近时比较效率，报告相同梯度计算预算和相同墙钟预算两种结果；
SAM同epoch约两倍反向成本，不能将其额外算力伪装成免费收益。

## 6. 文献依据与适用边界

- Turc et al., *Well-Read Students Learn Better*, 2019：https://arxiv.org/abs/1908.08962；
  小BERT出处，模型卡随权重保存。预训练模型被允许，不引入外部情感训练样本。
- Loshchilov & Hutter, *Decoupled Weight Decay Regularization*, ICLR 2019：
  https://arxiv.org/abs/1711.05101 。
- Foret et al., *Sharpness-Aware Minimization for Efficiently Improving Generalization*, ICLR 2021：
  https://arxiv.org/abs/2010.01412 。
- Yu et al., *Gradient Surgery for Multi-Task Learning*, NeurIPS 2020：
  https://arxiv.org/abs/2001.06782 。
- Chen et al., *GradNorm: Gradient Normalization for Adaptive Loss Balancing in Deep Multitask Networks*, ICML 2018：
  https://proceedings.mlr.press/v80/chen18a.html 。
- Tsai et al., *Multimodal Transformer for Unaligned Multimodal Language Sequences*, ACL 2019：
  https://aclanthology.org/P19-1656/ 。M3只借鉴跨模态注意力，不声称严格复现MulT。

这些工作提供可检验的建模/求解方法，不保证在本题上获得提升。
