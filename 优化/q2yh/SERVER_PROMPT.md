# 可直接交给服务器AI的执行指令

请执行本仓库“问题二”目录的`q2-plan-1.0`协议，完成局部模态缺失鲁棒情感预测。
本次授权范围为：在该目录内实现代码、训练候选、完成验证、冻结模型、生成附件3全部30条预测并回传结果。
不要只复述方案或停在“可以开始”；常规实现选择按配置和任务表执行，缺项/失败如实记录。

1. 先读`README.md`和`docs/`四份文档，再读两个`configs/*.json`。
   旧`ds/`只作参考，不覆盖它的源码、检查点、清单、正文和提交结果。
   原`问题一/`、`优化/`也不得更改；所有输出位于`问题二/runs/<新run_id>/`。
2. 定位附件2`aligned_50.pkl`和附件3`对齐版本`30个pkl，先运行本包的unittest、preflight和text encoder检查。
   附件3只有text_bert/audio/vision，没有预计算text。使用随包的小BERT统一文本通道；
   不拿问题一150维特征替代附件2的输入。
3. 本包已提供掩码、文本适配器和独立评价辅助代码；按`docs/服务器实施任务.md`实现尚未提供的
   数据分包、模型、训练、评价调度、冻结和发布入口。不能把辅助工具通过写成训练完成。
4. 固定原始有效域D、原生O和合成S。padding不算缺失，UNK不自动当真缺失；
   在原序列连续索引上造缺失，文本必须先遮挡再BERT编码。冻结BERT始终eval。
5. 先完成B0、B2、M1、CE+MSE对照和clean-only消融；先有完整回退模型，再做B1/B3/M2/M3与优化器。
   O1=AdamW；前两结构上再测SGD、SAM、PCGrad。GradNorm、蒸馏和专家后融合为有预算才开的P2。
   总训练run默认≤36，先测epoch吞吐，预留推理/报告/打包时间，不做全面参数穷举。
6. 只在train学参数，只在valid/select选结构、loss、阈值和集成。
   候选共用评价mask；最终比较补齐42/43/44三个训练种子。
   按冻结R_MAE容差和F1/最差MAE/体积次序选择，允许简单模型获胜，不挑最好种子。
7. 冻结后完成confirm库、类型×比例、start/middle/end和同步/独立窗口分析。
   保留逐样本预测，统计按video_id聚类，不能以21条件或5随机mask复本当独立样本。
   旧ds的test已曝光，新test仅作冻后描述性审计，不作为本项目首次盲测。
8. 附件3/4不得用于调参或按其缺失分布定制增强；附件3仅在最终冻结后推理30条，
   列为`sample_id,原文件名,polarity,intensity`，中性强度0、正负符号一致。
   同时报raw/published指标，保存发布规则，避免旧C2/C3错用。
9. 回传全部代码、精确环境锁、候选比较、失败实验、三因素结果、模型权重、输入/输出摘要、
   冻结清单、CSV/JSON及结果分析。最终清单在报告填好之后生成。
   所有new训练状态与既有ds数字分开，不允许把旧结果充作本轮结果。
10. 完整模型必须可在干净进程离线加载；共享BERT只存一份，
    Q1/Q2/Q3合包≤50,000,000字节。权重仅留服务器、提交包只留SHA不算完成。

最终汇报请明确：选了什么模型/优化器/损失、相对简单基线的实际提升与不确定度、
有无跨种子退化、附件3行数与SHA、权重是否齐全、总包体是否达标，以及哪些P2未执行。
