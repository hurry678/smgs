## 10. 给论文写作的可用结论

1. 本方案的**门控机制本身即是可写进论文的贡献点**：它用独立 confirmation 分区拦截了 selector 分区上的"看似提升"，说明多模态鲁棒性提升对分区选择敏感，单分区调参不可信。
2. 结果支持"**候选改进不稳健**"的诚实结论：R_MAE 有 +0.00059 的边际收益，但 R_F1 −0.00406 超过容差，属于收益—风险不对称。
3. 论文中建议同时呈现 selector / confirmation / full-valid 三个分区，并明确说明只有 confirmation 参与决策——这正好对应题目"分析缺失模态类型、缺失位置、缺失时长对预测性能的影响规律"的要求。
4. 计算成本（1.392 GPU-hours、峰值 1.306 GiB）可作为"轻量可复现"的实践价值证据。
