# 服务器实施任务与运行契约

## 1. 当前交付边界

本目录已提供协议、模型/优化器定义、参考掩码函数、冻结文本编码器、预检和独立指标重算工具。
**完整神经训练器、候选融合网络、mask库导出、模型选择器和最终发布器由服务器AI按下文实现。**
不得把本地工具测试通过写成“问题二训练已完成”。不要直接运行ds旧训练命令后贴成新方案结果。

下列任务在`问题二/`内部进行；引用ds仅作只读参考。不得向原数据目录写缓存，
不得修改`ds/`、`问题一/`、`优化/`和仓库根README；不得移动/删除原文件。

## 2. 环境与输入

使用Python3.10/3.11。默认参考Python3.11＋`requirements-core.txt`中的精确依赖；
先检查现有环境，不在现有全局环境中随意升级。需新依赖时在`问题二/.venv/`建立独立环境。
GPU版PyTorch从官方相应CUDA wheel源安装，记录实际版本（含CUDA后缀）、CUDA/cuDNN、
GPU型号、驱动、CPU、RAM、线程数、AMP状态、TF32状态、确定性设置、Git提交与源码SHA。
同一比较矩阵必须用同一个精确环境；发生环境变更应重跑受影响候选或分表，不能混排。

```bash
# 以下三个命令已经提供，可以直接运行
python -m unittest discover -s 问题二/tests -v
python 问题二/scripts/check_text_encoder.py \
  --output 问题二/runs/environment_check/text_encoder_check.json
python 问题二/scripts/preflight.py \
  --aligned "/实际路径/附件2-数据集特征文件/aligned_50.pkl" \
  --attachment3-dir "/实际路径/附件3-模态缺失特征样本/对齐版本" \
  --output-dir 问题二/runs/preflight_server
```

输出目录/文件已存在时换新的run_id，不能通过覆盖来伪装干净重跑。
`training_dependencies_ready=false`时先准备环境；输入预检通过不代表CUDA和优化器可用。
另测`torch.optim.AdamW`导入和一轮更新。若原环境缺sympy等依赖，修复独立环境，
不得未经逐步等价验证就以手写优化器替代官方实现。

## 3. 实施任务表

### T01：数据准备与mask库（先完成）

实现`src/data.py`、`scripts/prepare_data.py`、`scripts/build_mask_bank.py`：

- 从CLI接收原始路径，读取附件2后分别写`data/train.npz`、`valid.npz`、`test.npz`，
  `attachment3.npz`单独生成；保存原始ids、token_type、标签精度、原文件SHA。
- train入口只接受train/valid，不能接收test/附件3路径；不得使用Q1额外标签。
- 复用`protocol_core.interface_masks`的契约，N=1不能随意`squeeze()`掉多个维度。
- 保存D/O，按照train O计算normalizer；attention/UNK与padding分开。
- select/confirm/position/coupling库保存visibility、样本ID、全部区间记录、每样本SHA、
  条件SHA和库SHA。确认重复执行和batch重排后SHA相同；confirm库在选型阶段不评价。
- 库大小可用bool压缩NPZ；不把mask后的全部大张量复制105份，运行时按索引读取。

### T02：模型与第一轮训练

实现`src/models.py`、`src/losses.py`、`src/optimizers.py`、`scripts/train.py`：

- 首先B0/B2/M1，随后B1/B3/M2/M3；模型签名固定：
  `forward(text_bert, audio, vision, domain, visible) -> {logits, raw_intensity, diagnostics}`。
- `scripts/text_encoder.py`已提供可用冻结文本模块；所有候选共享原始同SHA权重。
  其forward要求缺失已经反映在visible中；不允许直接使用完整hidden缓存。
- padding-aware BiGRU、masked softmax全空分支、剩余证据池化与no-evidence先验。
  网络内mask侧通道属于模型特征；硬mask则是所有基线必须遵守的输入可见性约束。
- 首轮采用官方AdamW、L1 loss、固定d=64，另外保留用户CE+MSE对照。
- 每epoch仅用select库早停；默认全728条valid。吞吐不允许全评时在训练开始前按video_id
  冻结256条筛选子集并记录SHA，所有候选相同；最终排名仍用全728条，不使用文件前256行。
- 记录best epoch、完整历史、全部候选失败、训练/验证秒数、峰值显存、参数数、梯度范数、
  CE/回归梯度余弦（可每100步采样）、loss各项。评估始终eval，无随机dropout。
- 可断点续训需保存optimizer/scheduler/RNG/epoch/augmentation协议；
  最终部署检查点只保留推理权重及必要配置。冻结编码器不重复写入每个候选checkpoint。

### T03：统一评价、选型与消融

实现`scripts/evaluate.py`、`scripts/select_model.py`、`scripts/run_experiments.py`：

- 每个候选读取相同mask库，只在train/valid工作；可命令行显式选择已冻结后的test审计。
- 导出四指标、逐类F1/support、raw/published MAE/Pearson、冲突率、投影幅度、缺失实际比例。
- 原始预测建议NPZ长期保留、按需导出CSV用于独立复算，避免日志中写全部张量。
- `evaluate_predictions.py`可重算两个候选的发布指标和视频聚类配对区间。
  先对预测表做与预注册库的全量键覆盖检查；工具自身不替代完整实验矩阵验收。
- 按`configs/candidates.json`逐阶段执行，性能相同优先简单模型；不做全面笛卡尔积。
- SAM两次pass同mask/batch/RNG；PCGrad/GradNorm做独立小例子梯度方向检查再上全量。
- 如果M2/M3收益小、方差大，允许最后选B2/B3/M1，不能为了“创新”强选复杂结构。

### T04：冻后推理与打包

实现`scripts/freeze.py`、`scripts/predict_attachment3.py`、`scripts/package.py`：

- freeze保存selected config、训练种子/固定集成成员、encoder/task权重SHA、
  normalizer、input协议、mask库、发布策略、Git提交、各阶段完成状态。
- confirm/position/coupling只作冻后报告；如发生真实实现bug需新版本修复并报告，
  不把看过的confirm重新宣称为未见评估。
- 历史官方test已曝光，新版冻结后可作一次描述性审计；
  不以“test更好”决定上线，不按test改损失、阈值或集成规模。
- 附件3只推理不训练，全30条，保存CSV与JSON一致性和全部输入/权重摘要。
- 生成论文结果表、SVG图、失败案例与限制；没有数据的表格单元写null或not_run。
- 推理权重和Q1共享BERT去重；最终合包≤50MB，必须包含可运行模型参数，
  不接受“权重在服务器但提交包只有SHA”的交付。
- 若完整候选都不优于简单模型，交付简单模型＋失败对照，报告无明显优化收益。

## 5. 必须增加的实现测试

本包提供的16个测试覆盖参考协议；服务器需对实际Torch模型补测：

| 测试 | 判定 |
|---|---|
| O=0位置原始值任意改变 | 预测不变；除去不可用输入中的NaN后测试大数有限扰动 |
| 域外padding值/长度改变 | 语义输出不变（相同位置编码、eval、FP32容差1e-6） |
| 文本内部遮挡 | BERT前ID替换且attention=0；剩余上下文重算；缓存key变化 |
| 全空key / 全空样本 / 原生空模态 | 输出有限、权重和规则正确、保留样本 |
| train()调用 | 冻结BERT仍eval，参数不变、无梯度 |
| normalizer复用 | valid/test与附件3未重新fit；mask=0仍置0 |
| mask库重排复现 | 样本级SHA与模型/批量/GPU无关 |
| SAM/PCGrad实现 | 单步对照梯度/扰动回滚检查、双pass同缺失条件 |
| 发布结果回读 | 30ID、顺序、CSV/JSON、符号和数值精度一致 |
| checkpoint离线重载 | 相同输入预测与原模型一致，必需权重无漏项 |

这些测试验证任务机制和交付正确性，不要求堆砌与模型无关的安全测试。

## 6. 失败与回传

资源不足/OOM：先减batch并用梯度累积保持effective batch=64，同一比较候选同步配置；
无法保持时单列实验。不能只给最喜欢的模型更大预算。
某依赖无法安装：记录报错、版本与受影响阶段，优先交付已完成P0；
可替换实现需新配置ID和等价验证，不把未执行写completed。
缺原数据/模型权重时输出明确缺项路径，不编造预测，不用其他情感数据补齐。

回传必须至少包含：代码、环境锁、全部模型状态、预检、选择理由、全量预测、
缺失库SHA、三因素结果、指标重算、提交CSV/JSON、包体核验和完整SHA清单。
先生成报告再生成最终清单。只将本目录新增文件提交Git，原目录修改/删除必须为0。
