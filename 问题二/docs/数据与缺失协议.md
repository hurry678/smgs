# 数据接口、掩码和连续缺失协议

协议ID：`q2-mask-domain-1`。字段含义优先依据实际附件核验；只读原文件。

## 1. 输入契约与禁止混用

| 来源 | 实际接口 | 用途 |
|---|---|---|
| 附件2 aligned_50.pkl | train=3395、valid=728、test=727；每个split是按字段组织的dict | train学习参数、valid选择方案；test冻结后描述性审计 |
| 附件2 text_bert | `(N,3,50)`，依次input_ids、attention_mask、token_type_ids | 文本主通道，先检查数值为整数再转int64 |
| 附件2 audio / vision | `(N,50,74)` / `(N,50,35)` | 使用题给特征，非问题一自提取特征 |
| 附件2 text | `(N,50,768)` | 仅诊断参考；附件3缺少此字段，不能直接作为部署主线 |
| 附件3 对齐版本 | 30个pkl，每个顶层`test`，字段仅text_bert/audio/vision；前面有N=1维 | 单独去掉N=1维，再堆叠为30条；ID从原文件名取得 |
| 附件4 | 问题三范围 | 本轮不调用、不调整模型 |

附件3_01、_03、_30等已直接核验。附件3的text_bert不是向量，不能把3个整数通道当连续语义embedding；
它也不提供sample id/raw_text，不能从其他附件相似样本搜索出缺失内容。
不能使用一套版本训练、另一套推理，也不能同时拼入aligned和unaligned。
非对齐版曾出现vision_lengths之外仍有非零行，暂列后续独立路线，当前不为它增加实现分支。

同一小BERT词表30522项；PAD/UNK/CLS/SEP/MASK应为0/100/101/102/103。
`[UNK]`是合法未知词元，不能仅凭UNK或恰与音视频零位置重合就宣布找到了真实缺失生成器。
原始attention全1的UNK位置仍按文本观测处理，可在日志记录unknown flag；主模型不增加基于附件3统计定制的特征。

没有提供精确逐词时间戳，50个对齐位置也不是50个等长秒窗。
“时长”分析主要报告连续位置数量和有效长度占比，不能把20%序列长度写成20%真实秒数。

## 2. 三类掩码

1. **有效时序域D**：由原始输入中唯一SEP的位置定义，排除位置0的CLS和SEP本身，
   即`0<t<sep_index`。不能用当前可见attention之和缩短有效域，否则内部缺失被误认成padding。
   若CLS/SEP不存在或有歧义，预检拒绝；由服务器记录具体样本并修订接口版本，不能猜测长度。
2. **原始可观测O**：text为域内原始attention=1且ID不是PAD/MASK；
   audio/vision为域内原始float32整行不全为0。非有限值导致预检失败，不能先nan_to_num再声称数据正常。
   域外数据即使非零也不参与计算，记录域外非零行数量。某一合法维为0不应被整行掩掉。
3. **合成保留S**：初始全1，选中模态的连续原始索引窗口置0，`M=D∧O∧S`。
   必须满足`M⊆O⊆D`；缺失增强永不恢复原生缺失。

归一化仅用train中O=1行计算逐维均值与标准差（float64统计、float32输入，std下界1e-5）。
加载valid/test/附件3时使用冻结统计。归一化后重新把M=0行置0；
M从原始数值计算并保存，不能再由标准化后的0判断缺失。
原始回归label保持float32，不照搬ds把label压成float16。

## 3. 编码前遮挡

对合成文本缺失：

```text
ids_missing[M_text==0 & D] = 103
attention_missing[M_text==0 & D] = 0
所有域外padding attention = 0
CLS/SEP 保留为编码器内部支撑，不进入融合池化
BERT.eval(); requires_grad_(False)
encoded = BERT(ids_missing, attention_missing, token_type_ids)
text_hidden = encoded * M_text
```

模型train()之后必须显式令冻结编码器eval()，不能让其dropout随融合头训练打开。
缓存完整文本hidden只能服务完整视图；缺失视图必须重新编码。
如果缓存缺失视图，key应包括模型SHA、ids、attention、type ids、合成mask；不得以sample_id单独缓存。
内容泄漏测试：保持可见输入相同，任意改变被mask位置的原始ID/音视频值，预测必须保持一致。

可选鲁棒性附表可固定使用UNK替换但保留attention的“未知词元扰动”；
它不等同主协议的已知缺失，掩码不能从不可见生成标签偷传给推理模型。
该附表不影响主排名，不能因看到附件3的UNK数量重新训练或选阈值。

## 4. 连续窗口生成

在每条样本的原始有效域索引 `[first,last]` 上取长度：

`k=max(1, floor(rho*L_domain+0.5))`，上限`L_domain-1`。

窗口必须是原始索引连续区间，**不能先删自然缺失位置再在压缩序列上抽窗口**。
对被选择且至少有2个原始观测的模态，只允许：

- 窗口内至少删1个原始观测；
- 窗口外至少留1个原始观测。

不满足时从合规窗口中按位置规则选择；无窗口则记录`skipped_no_eligible_window`并保留样本。
原模态只有0或1个观测时记录`skipped_lt2_observed`，不把它伪造成整模态缺失。

位置规则：start选最靠前合规窗口；middle选窗口中心最接近域中心者（平局选左）；
end选最靠后；random在合规窗口中均匀选。有限长度/自然孔洞导致实际位置偏移时必须记录。

多模态窗口提供两个清楚区分的版本：

- `independent`（主协议）：每模态独立抽窗口；
- `synchronized`（机制验证）：所选且可遮挡模态使用同一个原始索引窗口。
  共同合规窗口为空则整次同步遮挡跳过并记录，不偷偷切换成独立窗口。

稳定随机键：
`(protocol_id, mask_seed, split, sample_id, subset, rho, placement, replica, coupling, modality)`。
与模型名、训练初始化种子、batch顺序、GPU数无关。评价库对所有模型完全一致。
训练增强另用`augmentation_seed`和epoch，可每轮变化，不能读取valid评价库。

每样本/模态保存：L_domain、O_count、M_count、请求rho、窗口start/stop（左闭右开）、
实际窗口占域比例、新删除比例`(O_count-M_count)/O_count`（原本空模态为null）、
原生缺失率`1-O_count/L_domain`、最终缺失率`1-M_count/L_domain`、跳过原因。
不能把“请求遮挡50%”等同“实际总缺失率50%”。

## 5. 训练与验证分离

官方train/valid/test保持原ID与分组；本轮不得将问题一100条样本合并训练。
已知问题一有7条与附件2 test重叠，因此尤其不能导入其情感标签参与第二问训练。

P0训练：每条train样本每epoch使用一个完整视图＋一个合成缺失视图，loss各0.5；
随机选7种非空模态子集，默认各1/7，rho在{0.1,0.3,0.5}等概率，
原始索引连续窗口、independent、随机位置。另以相同结构和优化器训练clean-only对照，
避免把数据增强收益误归为掩码注意力。

均匀子集只是预注册默认，不代表它优于ds的70%单模态/25%双模态/5%三模态分布；
后者可作一次训练分布对照，必须在valid选择，不能根据附件3分布来定增强概率。

验证库事先分开：

- `select`：mask_seed=20260925，7子集×3比例×3复本=63缺失条件＋clean，用于早停和候选筛选。
- `confirm`：mask_seed=20261001，7子集×3比例×5复本=105缺失条件＋clean。
  只在最终选择冻结后使用，报告对新缺失位置的稳定性；样本仍是同一valid，不能称独立新数据集。
- `position`：3单模态×3比例×start/middle/end=27条件。位置确定，不用复制相同mask伪造随机复本。
- `coupling`：4个多模态子集×3比例×5复本的同步窗口60条件；与confirm中的对应independent对比。
- `stress`（可选）：更高缺失比例、多段短缺失、整模态缺失仅作域外压力测试，
  不与局部缺失主任务混为一谈。

无法遮挡的样本仍参与全体指标，另报告实际受到新增遮挡的子集指标、数量及自然缺失子集，
防止“遮挡未生效”造成虚高鲁棒性。不同模型不得删不同样本。

## 6. 数据溯源与接口审计

`preflight.py`读取原始文件哈希、shape、train/valid标签范围/符号、ID分组交叉、
CLS/SEP、词表范围、原生缺失和域外非零等信息；附件3只写接口与全量ID检查。
pickle容器一次反序列化会把test对象载入内存，这不等于训练使用test：
准备脚本必须将train、valid、test物理分成独立文件，训练入口不接受test路径。
test只检查shape/ID隔离，不输出其标签分布或评价分数。

所有路径参数由命令行传入，不硬编码服务器账号或绝对工作目录。
模型按相同编码器hash、normalizer hash、mask协议hash加载；
原ds检查点只可作为标为`legacy_reference`的参考，不能直接加载为本轮小BERT模型。
