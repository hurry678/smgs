# 问题一实验数据说明与使用规范

本文件规定系统对比实验如何使用E题四个附件。原则是“全部盘点、按题意使用、测试集不调参、原始数据不修改”。

## 1. 数据角色

| 数据 | 可用于 | 不可用于 |
|---|---|---|
| 附件1：100条原始视频、转写与标签 | 三套问题一候选的全量提取；覆盖/边界/效率/表示探针；异常分层 | 删除静音或困难样本；修改原文或标签；用当前边界生成真值 |
| 附件2：train/valid/test处理特征 | 核对问题二、三的输入维度、词元及ID接口；必要时确认迁移接口 | 代替问题一原视频特征；用test标签选问题一方案 |
| 附件3：无标签缺失专项测试 | 统计文件结构、零段/掩码机制，验证下游能读取问题一的缺失语义 | 选择超参数、比较情感准确率、推断“最优”方案 |
| 附件4：无标签解释专项视频与特征 | 核对关键证据能映射到原文、音频时段和视频帧 | 作为有标签验证集或调参集 |
| 当前 `第一问/` 版本 | 候选A的代码、模型锁、100条输出、独立ASR审计 | 将ASR时间当人工真值 |
| Git `问题一/` 版本 | 候选B的代码、100条输出及历史候选筛选 | 将历史筛选分数当A/B/C同条件比较 |

## 2. 输入定位与完整性

服务器根目录记为`${E_ROOT}`，至少包含：

```text
${E_ROOT}/
  E题数据/
    附件1-数据集原始多模态样本/
      MOSEI数据集部分原始视频-100条/
        label-100.xlsx
        <video_id>/<clip_id>.mp4
    附件2-数据集特征文件/
      aligned_50.pkl
      unaligned_50.pkl
      label.xlsx
    附件3-模态缺失特征样本/
      对齐版本/*.pkl
      未对齐版本/*.pkl
    附件4-可解释专项视频样本与特征文件/
```

正式运行前执行`run_q1_comparison_protocol.py --stage preflight`。附件1必须恰有100条MP4；附件2三个文件齐全；附件3两种版本分别30个文件；附件4目录存在。随后核对附件1的`video_id + clip_id`无重复，100条视频与标签一一对应，并保存源SHA-256。

## 3. 附件1预处理

所有候选共享以下不可变输入：

1. 样本ID统一为`video_id$_$clip_id`。
2. 原始转写保持Unicode字符不变；各方案可使用自己的分词器，但必须保存字符范围。
3. 情感`label`和`annotation`不参与特征提取、时间边界或异常规则。
4. 音频解码为16kHz单声道时，仍需对原始多声道执行独立静音审计，防止声道抵消。
5. 视频使用原始显示时间戳；若候选按帧率推算时间，必须另存与ffprobe PTS的偏差。
6. 原始视频、标签和源摘要只读，任何清洗都以派生状态或掩码记录。

## 4. 分层与拆分

### 4.1 冒烟集

冒烟集6条，至少包含：

- 短、中、长各1条；
- 1条数字静音；
- 1条语音边界不可用或ASR零匹配；
- 1条视觉全缺失或主体歧义。

同一条可承担多个属性，但总数保持6条。冒烟结果只验证流程，不进入正式性能汇总。

### 4.2 表示探针折分

分组键必须为`video_id`，不是`sample_id`。同一原视频的不同clip禁止跨折。

- 外层：5折，评估泛化。
- 内层：3折，只做正则/投影选择。
- 重复：固定5个种子`20260924`至`20260928`。
- 标准化：每个外层训练折内拟合；不得在100条上整体拟合。
- 输出：每个外层测试样本的预测、折ID、组ID和真实标签。

数据量只有37个原视频分组，故不使用复杂深层探针。逻辑回归与Ridge的目的是衡量冻结表示可线性读取的信息，避免优化器和网络容量成为主要混杂因素。

### 4.3 人工边界子集

推荐20条分层样本、至少两名标注者。分层覆盖：

- 数字静音和非静音不可对齐；
- 独立ASR零匹配；
- MFA与其他方法分歧最大；
- 短/中/长；
- 低视觉有效率、多人和小脸；
- 三类情感标签仅用于覆盖性平衡，不允许查看待评边界后选样本。

标注者从原音轨和原视频独立给出词或短语边界。先冻结初始标注，再计算标注者间差异；共识修订必须记录双方身份代号、时间和原因。没有人工标注时，报告中的人工误差字段保持`null`。

## 5. 附件2—4使用边界

附件2的`text_bert`是三路整数输入，不是语义向量。若检查文本接口，应使用兼容BERT编码器；不得把token ID直接作为连续特征。

附件3先统计真实零段的模态、位置、长度和共现方式，再用于问题二缺失协议。问题一仅检查自身的`valid`掩码能否无歧义映射到该接口。

附件4用于验证解释输出的时间位置能回到原始文本、音频和视频。问题一候选必须保存字符范围、秒数和原始帧PTS；仅有特征索引不算完成映射。

## 6. 防泄漏规则

- 不读取附件2 test、附件3、附件4的标签；后两者题面本身无标签。
- 不根据附件1情感标签调整VAD、F0范围、人脸阈值、短语合并或缺失规则。
- 不以全100条探针结果反复修改候选后仍称为独立验证；修改候选即提升协议版本并重跑固定外层折。
- 不把同一`video_id`拆到训练和测试两侧。
- 不使用测试折统计量做标准化、PCA、特征选择或早停。
- 不从候选边界复制出“人工参考值”。

## 7. 数据与结果保留

必须保留：

- 输入清单、源摘要和数据角色；
- 折分清单与随机种子；
- 原始自动结果、人工参考和修订结果的独立文件；
- 每样本失败与回退状态；
- 配置、代码、模型、环境和输出摘要；
- 全部100条结果，不只保留成功或高置信样本。

不得上传题给原视频或其他受限原始附件到公开Git仓库。仓库只保存代码、协议、允许分发的派生统计、图表、元数据和必要的小型示例。
