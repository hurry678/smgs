## 0. 结论摘要

1. 问题三沿用问题二冻结预测器 **M3-ensemble9 + C2**，不再为附件4重新训练或调参。模型由9个M0双任务checkpoint组成，验证集完整指标为：

5. 附件4共20条，预测分布为 Negative 7、Neutral 3、Positive 10；强度范围 `[-2.4232094, 1.3042946]`。主要参考模态计数为 text 12、audio 5、vision 3。

### 2.2 集成输出

```text
p_bar_c = (1/9) * sum_k p_k,c

```

```text
c_hat = argmax_c p_bar_c
```

## 3. 可解释性数学模型

### 3.1 符号

令模态集合：

```text
M = {text, audio, vision} = {t, a, v}
```

对样本 `x`、解释目标类别 `c_hat`，定义模态子集 `S ⊆ M` 下的输出函数：

```text
v_c(S) = log p_bar_c(x_S)
```

其中 `x_S` 保留集合 `S` 中的模态，未保留模态的可用性掩码置为缺失状态。强度解释使用：

```text
v_y(S) = y_bar_raw(x_S)
```

### 3.2 精确三模态Shapley

模态 `m` 的分类Shapley值为：

```text
phi_m^c = sum_{S ⊆ M\{m}}
          [ |S|! (3-|S|-1)! / 3! ] * [ v_c(S ∪ {m}) - v_c(S) ]
```

强度Shapley值同理：

```text
phi_m^y = sum_{S ⊆ M\{m}}
          [ |S|! (3-|S|-1)! / 3! ] * [ v_y(S ∪ {m}) - v_y(S) ]
```

三模态只有8个子集，因此可精确枚举，不需要蒙特卡洛近似。精确枚举保证：

```text
sum_m phi_m^c = v_c(M) - v_c(empty)
sum_m phi_m^y = v_y(M) - v_y(empty)
```

实验中最大加和误差为 `1.1921e-7`，达到float32数值误差量级。

### 3.3 LOO对照

留一法定义为：

```text
LOO_m^c = v_c(M) - v_c(M\{m})
```

LOO只评价“从完整三模态中删除该模态”的边际影响，不能分配模态间交互，且不满足一般Shapley加和结构。它与Shapley用于主模态一致性检查，而不是替代Shapley。

### 3.4 连续窗口遮挡

设模态 `m` 的有效位置序列为 `P_m`，窗口大小 `w`、步长 `s`。第 `j` 个连续窗口为：

```text
W_mj = {p_j, p_{j+1}, ..., p_{j+w-1}}
```

遮挡后的分类目标分数变化定义为：

```text
Delta_c(m,j) = v_c(M) - v_c(M; W_mj occluded)
```

强度变化：

```text
Delta_y(m,j) = v_y(M) - v_y(M; W_mj occluded)
```

这里采用实际遮挡重算，不使用梯度近似替代最终分数。

### 3.5 同预算对照

对每个连续窗口，构造位置数量相同的两类对照：

1. **随机连续窗口**：从有效位置中等长随机截取连续片段；
2. **点散遮挡**：从有效位置中随机选择相同数量、尽量非连续的位置。

连续窗口、随机连续窗口和点散遮挡使用相同删除预算。比较指标为 `|Delta_c|` 的配对差值、胜/负/平计数、5000次配对Bootstrap 95%置信区间和精确双侧符号检验。

### 3.6 证据方向与排序

- 支持证据：`Delta_c > 0`，即遮挡后目标类得分下降；
- 反证证据：`Delta_c < 0`，即遮挡后目标类得分反而上升；
- 无支持证据：没有任何正贡献窗口超过数值阈值，必须输出原因，不能伪造证据。

窗口排序同时使用分类贡献与原始强度变化的百分位，并按模态分别取 `top-k`。最终冻结 `top_k_per_modality=2`。

### 3.7 主要模态

对每个样本计算分类绝对作用占比和强度绝对作用占比：

```text
share_c,m = |phi_m^c| / sum_j |phi_j^c|
share_y,m = |phi_m^y| / sum_j |phi_j^y|
```

综合模态作用程度：

```text
effect_m = 0.5 * (share_c,m + share_y,m)
```

主要模态为：

```text
m_primary = argmax_m effect_m
```

同时输出最强影响模态、支持模态、分类/强度贡献和归一化作用占比。

### 3.8 证据等级

证据等级按窗口排名和控制对照击败率确定：

```text
high   : rank >= 0.8 且 control_beat_rate >= 0.75
medium : rank >= 0.5 或 control_beat_rate >= 0.5
low    : 其他
```

该等级描述局部证据在既定解释器中的相对强度，不表示统计显著性，也不表示物理因果强度。

## 6. 备选方法比较

| 方法 | 理论优势 | 局限 | 本方案处理 |
|---|---|---|---|
| 精确Shapley | 满足效率、对称性、虚拟参与者和可加性；能分配交互 | 需要定义遮挡基线；计算随模态数指数增长 | 三模态仅8个子集，选为主方法 |
| LOO | 直观、计算少 | 无法分配交互，结果依赖“完整集合删除一个”的路径 | 作为主模态一致性对照 |
| 注意力热图 | 无需额外前向，易可视化 | 注意力权重不等于预测贡献，不能证明证据忠实 | 不作为问题三解释结果 |
| 连续窗口遮挡 | 与题目“连续局部片段”直接对应，输出可回看区间 | 结果依赖窗口长度、步长和遮挡基线 | 选为局部证据主方法 |
| 点散遮挡 | 检查单点分散影响 | 破坏连续片段的时序语义，证据不可直接回看为连续事件 | 仅作同预算对照 |
| 随机连续窗口 | 控制窗口长度和连续结构 | 位置随机，不针对模型主要依据 | 仅作同预算对照 |

问题三的对比重点是“模态级归因方法”和“局部证据搜索结构”，不是再次比较预测模型。预测模型对比已在问题二完成并冻结。

### 11.2 可直接使用的结论

- 三模态只有8个联盟，可精确计算Shapley，无需采样近似；
- Shapley同时给出分类和强度两套模态贡献；
- 局部证据通过真实遮挡重算，而非仅给注意力热图；
- 文本证据可精确回看；
- 输出结构支持“预测-作用-定位”逐级追溯；
- 预测器与解释参数均在附件4推理前冻结，版本可复现。

### 11.3 必须避免的表述

- 不能把Shapley值称为物理因果效应；
- 不能把遮挡贡献解释为模型之外的真实情感机制；
- 不能把音视频比例映射称为精确时间戳或精确关键帧；
- 不能声称连续窗口在统计上普遍优于所有对照；
- 不能把解释分数当作预测正确性的证明；
- 不能用附件4结果反向调参后仍声称是冻结推理。

## 12. 局限性与风险

1. **遮挡归因非物理因果**：解释的是模型在给定遮挡基线下的行为，不是现实世界的因果机制。
2. **基线依赖**：模态Shapley和窗口遮挡都依赖缺失状态的定义；换基线可能改变数值。
3. **音视频定位近似**：附件4缺少原始词级时间戳，只能比例估计。
4. **连续窗口优势有限**：w10提高证据集中度，但相对随机连续窗口未显著占优。
5. **解释与预测正确性分离**：解释忠实于冻结模型，不等于预测标签正确。
6. **附件4无标签**：只能报告预测和解释结果，不能在附件4上计算Accuracy、F1、MAE或Pearson。
7. **样本规模小**：附件4仅20条，其解释统计不能用于大范围推广。
8. **证据区间存在交互**：多个窗口可能重叠，窗口分数不能严格相加为Shapley模态贡献。
