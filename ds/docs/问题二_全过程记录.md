## 0. 结论摘要

问题二针对文本、语音、视觉中部分连续时段不可用的场景，建立了显式缺失感知的多模态情感预测模型。当前正式版本为：

```text
M3-ensemble9
成员：M0 的 seeds 42–50，共 9 个检查点
融合：softmax 概率平均；raw intensity 平均
发布策略：C2
C3阈值仅作参考：(-0.20, 0.35)
```

版本选择严格限定在验证集：对7种非空模态子集、3种缺失比例、5个固定随机复本组成的21个“子集×比例”条件等权计算平均强度MAE，记为`R_MAE`；随后比较缺失条件Macro-F1、最差条件MAE和完整输入指标。官方test和附件3均未参与模型选择。

验证集核心结果：

| 指标 | 旧版 M0 seed42 | 当前 M3-ensemble9 |
|---|---:|---:|
| 21条件平均MAE（C2） | 0.610839 | **0.604523** |
| 最差条件MAE（C2） | 0.656917 | **0.650466** |
| 缺失条件平均Macro-F1（C2） | 0.567132 | **0.572749** |

## 1. 题目要求与任务边界

### 1.1 任务要求

问题二要求在模态局部缺失条件下稳定输出：

1. 情感极性：Negative、Neutral、Positive；
2. 情感强度：与原始连续情感标签对应的数值预测。

局部缺失的含义是某一模态的部分连续时间段不可用，而不是该模态在整条样本中完全不存在。模型必须分析：

- 缺失模态类型；
- 缺失位置；
- 缺失时长或缺失比例；
- 不同条件对分类和强度预测的影响。

### 1.2 输入与输出

输入使用附件2对齐后的三模态序列，并保留显式有效性mask：

```text
text_bert: [N, 50, 3]
audio:     [N, 50, 74]
vision:    [N, 50, 35]
```

其中：

- 文本通道0为token id，通道1为attention mask，通道2为token type；
- 语音和视觉均由问题一处理流程统一到50个时序位置；
- 文本BERT为冻结的MiniLM预训练编码器；
- 辅助诊断基线B1另使用旧版768维文本特征，不进入M0主模型。

输出为：

```text
logits:          [N, 3]
raw_intensity:   [N]
```

最终发布同时产生离散极性和带符号情感强度。

### 1.3 评估指标

分类使用Accuracy和Macro-F1；强度使用MAE和Pearson相关系数。模型选择的主指标为21个缺失条件的等权平均MAE：

```text
R_MAE = (1 / 21) * sum_{c=1}^{21} MAE_c
```

次指标为最差条件MAE，稳定性参考为完整输入Macro-F1。该规则避免只优化平均表现而忽略困难缺失条件。

## 2. 数据审计与统一输入

### 2.1 数据规模与划分

数据审计结果如下：

| 划分 | 样本数 | 视频组数 | Negative | Neutral | Positive | 原始空文本 |
|---|---:|---:|---:|---:|---:|---:|
| train | 3395 | 1528 | 967 | 758 | 1670 | 0 |
| valid | 728 | 239 | 206 | 184 | 338 | 0 |
| test | 727 | 381 | 207 | 158 | 362 | 0 |

审计确认：

- train、valid、test的样本ID均唯一；
- 三个划分之间没有样本ID交叉；
- 三个划分之间没有视频组交叉；
- 分类标签均为0/1/2；
- 连续标签均位于`[-3, 3]`；
- 数值均为有限值；
- 原始文本均非空。

### 2.2 原始模态有效性

原始mask统计如下：

| 划分 | 文本有效率 | 语音有效率 | 视觉有效率 | 视觉全缺失样本 |
|---|---:|---:|---:|---:|
| train | 0.492913 | 0.452530 | 0.427882 | 110 |
| valid | 0.511758 | 0.470495 | 0.444835 | 15 |
| test | 0.503686 | 0.463686 | 0.435516 | 28 |

零向量不被自动解释为有效观测。文本有效位置由attention和特殊token规则共同确定；语音、视觉有效位置由数值和原始mask共同确定。

### 2.3 特殊位置与可遮挡位置

`[CLS]`、`[SEP]`和padding不参与合成缺失遮挡。模型可以保留这些位置用于BERT内部编码，但缺失比例统计只使用真正的语义位置。由此避免：

- 把padding计入缺失率；
- 把特殊token当作可删除的情感证据；
- 在合成缺失时制造不真实的空序列；
- 把零填充与真实零特征混淆。

### 2.4 合成缺失协议

验证集和训练增强使用以下协议：

```text
非空模态子集：7种
{(text), (audio), (vision),
 (text,audio), (text,vision), (audio,vision),
 (text,audio,vision)}

缺失比例：0.1、0.3、0.5
随机复本：每个条件3个
随机位置：由样本ID、复本、种子稳定生成
位置分析：start、middle、end
```

对于某模态已有`L`个有效语义位置，遮挡数量为：

```text
k = min(L - 1, max(1, round(rho * L)))
```

至少保留一个原始有效位置，避免把“局部缺失”误变成“整模态完全不存在”。

## 3. 多模态情感预测数学模型

### 3.1 符号定义

| 符号 | 含义 |
|---|---|
| `i` | 样本编号 |
| `t` | 统一时序位置，`t=1,...,50` |
| `m` | 模态，`m in {text, audio, vision}` |
| `x_{i,t,m}` | 第`i`个样本、时刻`t`、模态`m`的输入特征 |
| `o_{i,t,m}` | 有效性mask，1表示可观测，0表示缺失 |
| `h_{i,t,m}` | 模态内时序表示 |
| `q_{i,t}` | 连续缺失结构向量 |
| `z_{i,t}` | 跨模态融合后的时刻表示 |
| `zbar_i` | 样本级情感表示 |
| `y_i` | 情感类别标签 |
| `r_i` | 连续情感强度标签 |

### 3.2 模态内编码

语音和视觉先经过线性投影、LayerNorm和GELU，再加入位置编码，由单层双向GRU编码：

```text
p_{i,t,m} = GELU(LayerNorm(W_m x_{i,t,m} + b_m)) + pos_t
h_{i,t,m} = BiGRU(p_{i,t,m})
h_{i,t,m} <- h_{i,t,m} * o_{i,t,m}
```

文本使用冻结的BERT编码词级上下文，再由同样的时序编码器处理：

```text
u_{i,t,text} = BERT(input_ids_{i,t}, attention_mask_{i,t})
h_{i,t,text} = TemporalEncoder(u_{i,t,text}) * o_{i,t,text}
```

冻结BERT的目的不是降低建模难度，而是：

1. 减少小样本下的过拟合风险；
2. 保持预训练语言语义能力；
3. 把可训练容量集中在融合和缺失鲁棒性模块；
4. 与题目允许使用开源预训练模型的要求一致。

### 3.3 M0连续缺失结构向量

M0的关键不是额外堆叠网络，而是把缺失的几何结构显式编码为`q_{i,t}`。对每个模态分别构造8类局部统计：

```text
o_{i,t,m}                    当前是否可观测
local5_{i,t,m}               长度5窗口内观测率
run_{i,t,m}                  当前连续缺失长度
left_{i,t,m}                 到左侧缺失边界的距离
right_{i,t,m}                到右侧缺失边界的距离
global_rate_{i,t,m}          该模态全局观测率
max_run_{i,t,m}              最长连续缺失长度
n_runs_{i,t,m}               缺失片段数量
```

三个模态合计24维；再加入3维全局观测统计和7维非空模态子集one-hot，得到：

```text
dim(q_{i,t}) = 3 * 8 + 3 + 7 = 34
```

`q_{i,t}`同时描述“当前是否缺失”和“缺失有多长、位于何处、是否形成连续片段”。这正是普通动态门控无法仅靠隐藏状态可靠推断的信息。

### 3.4 模态门控融合

在时刻`t`，模型只对可观测模态分配权重：

```text
r_{i,t,m} = MLP([h_{i,t,m}; q_{i,t}])
w_{i,t,m} = masked_softmax(r_{i,t,m})
z_{i,t} = sum_m w_{i,t,m} * h_{i,t,m}
```

当某模态完全不可观测时，其门控权重被mask置零；模型不会把零填充解释为中性情感证据。

### 3.5 时间门控与样本级聚合

融合后的时刻表示还需判断哪些时间位置对最终情感更重要：

```text
s_{i,t} = MLP([z_{i,t}; q_{i,t}])
beta_{i,t} = masked_softmax(s_{i,t})
zbar_i = sum_t beta_{i,t} * z_{i,t}
```

该设计允许模型在缺失边界附近降低不可靠时刻的权重，并把剩余有效证据聚合到样本级表示。

### 3.6 双任务输出

共享表示`zbar_i`连接两个任务头：

```text
logits_i = W_cls zbar_i + b_cls
raw_i = 3 * tanh(W_reg zbar_i + b_reg)
```

分类头输出3类情感，回归头输出`[-3,3]`范围内的连续强度。

### 3.7 损失函数

总损失由完整输入损失和合成缺失损失组成：

```text
L_cls = weighted_cross_entropy(logits, y)
L_reg = SmoothL1(raw, r, beta=1)
L_task = L_cls + L_reg
L = L_task(full_observation) + lambda_miss * L_task(synthetic_missing)
```

正式参数为：

```text
lambda_miss = 1.0
```

训练时同时使用完整观测和局部遮挡样本，使模型学习在信息缺失时保持输出稳定。

### 3.8 C2与C3发布策略

C2直接使用分类头：

```text
class = argmax(logits)
intensity =
  max(raw, 1e-4),   if class = Positive
  min(raw, -1e-4),  if class = Negative
  0,                if class = Neutral
```

C3仅使用回归值阈值：

```text
class = Negative,  if raw < dn
        Positive,  if raw > dp
        Neutral,   otherwise
```

正式冻结阈值为`dn=-0.20, dp=0.35`。C3保留为对照，不作为最终发布策略。

## 4. 候选模型与理论比较

### 4.1 模型族

| 模型 | 结构 | 理论优势 | 主要局限 | 选型结论 |
|---|---|---|---|---|
| B0 | 训练集常量/多数类 | 无参数、审计基线 | 不能利用任何模态和强度信息 | 仅作下界 |
| B1 | 旧768维文本时序均值 + LogisticRegression/Ridge | 简单、训练快、可解释 | 单模态、无时序交互、文本缺失时性能必然下降 | 诊断基线 |
| B2 | 冻结BERT + BiGRU文本双任务 | 文本语义强，参数量少 | 完全依赖文本，无法处理文本局部缺失 | 被淘汰 |
| B3 | 三模态时序编码 + masked mean拼接 | 实现简单、对模态缺失天然容忍 | 等权池化，忽略局部置信度与缺失结构 | 被淘汰 |
| B4 | BiGRU + 普通动态门控 | 能学习模态权重和时间权重 | 缺失状态由隐藏表示间接推断，连续缺失信息不可辨识 | 容量匹配对照 |
| B5 | BiGRU + 低秩双线性融合 | 能建模成对模态交互 | 成对聚合在局部稀疏时不稳定，参数效率不占优 | 被淘汰 |
| M0 | B4 + 34维连续缺失结构`q_t` | 显式编码缺失类型、位置、长度和边界，理论最贴合题目 | 依赖缺失mask质量；随机种子稳定性仍需提升 | 正式选用 |

### 4.2 为什么以B4为主要对照

B4包含普通动态门控和时间门控，且参数量略多于M0：

```text
B4 trainable params: 366,990
M0 trainable params: 349,446
```

因此，M0若优于B4，不能归因于扩大可训练容量。这个等预算式对照比只与B3或B5比较更能支持“连续缺失结构本身有价值”的结论。

### 4.3 为什么没有选择B5

低秩双线性融合适合显式建模模态交互，但问题二的核心是局部缺失。B5的成对特征需要在两个模态同时可观测的位置上聚合，缺失越严重，可用交互位置越少；同时，它没有直接表达连续缺失长度和边界距离。B5在验证集上表现接近B3/B4，但没有形成稳定优势，因此不作为最终模型。

## 11. 论文写作建议

问题二论文建议按以下逻辑组织：

1. 先定义局部缺失与完整模态缺失的区别；
2. 用mask和可观测子集描述缺失模式；
3. 说明M0的`q_t`为什么能表达缺失类型、位置和长度；
4. 给出模态门控和时间门控公式；
5. 用B0–B5/M0对比说明模型选择；
6. 用B4–M0等预算消融证明改进来源；
7. 报告多种子均值和标准差，不隐藏seed44退化；
8. 报告按模态、比例、位置的敏感性；
9. 用官方test单次结果作为最终泛化证据；
10. 单独说明C2/C3发布策略和C3误用纠错。

论文中应避免以下表述：

- “M0显著优于B4”；
- “缺失位置对性能没有影响”；
- “零向量表示缺失”；
- “附件3用于调参或选型”；
- “官方test经过多次评价后取最好”；
- 把C3阈值解释为正式发布策略。

更严谨的表述是：

> 在验证集21个局部缺失条件上，M0相对容量匹配的B4在seed42和seed43取得较小但一致的平均MAE优势，seed44出现退化，说明连续缺失结构具有有限收益且随机稳定性仍需提升。综合考虑理论贴合度、验证表现和缺失可解释性，本文选择M0 seed42并使用C2发布策略。

## 12. 局限性

1. M0的平均优势较小，且没有跨全部种子稳定成立；
2. 当前主要验证随机连续缺失，start/middle/end仅使用单复本；
3. 合成缺失由mask生成，不能完全替代真实采集中的传感器失效机制；
4. BERT冻结降低了过拟合风险，但也限制了文本语义适配能力；
5. 视觉特征来自问题一的轻量人脸区域特征，不包含主说话人跟踪和表情语义模型；
6. 测试集只评价一次，符合方法学要求，但不能据此进行阈值反复搜索；
7. 论文若需要显著性结论，应增加独立随机复本和配对检验，而不能仅凭当前3个种子推断总体显著性。

## 14. 统一缺失掩码增强复核（2026-09-24 17:28 CST）

### 14.1 改进动机

原验证协议把训练随机种子同时用于合成缺失掩码。这样不同模型种子面对的是不同缺失场景，模型初始化方差与缺失场景难度变化相互混杂。该问题不改变正式模型和附件3提交，但会削弱B4与M0等候选模型的配对可比性，因此进行了评价协议修正。

### 14.2 增强协议

新增独立脚本`scripts/q2_eval_robustness.py`，不修改冻结脚本`scripts/q2_eval.py`、模型检查点、官方test结果和附件3正式提交。

- 训练种子`train_seed`只控制模型权重；
- 所有15个冻结检查点统一使用`mask_seed=2026`；
- 随机连续缺失复本由3组增加到5组；
- 评价覆盖7种非空模态子集×3种缺失比例×5复本，共105个随机缺失条件；
- 另评价3种单模态×3种比例×3种位置，共27个连续位置条件；
- 主比较指标仍为C2策略下21个“模态子集×比例”条件的等权平均MAE，即`R_MAE`；
- 每个条件保存布尔可见性mask的SHA-256。

掩码一致性审计结果：

```text

mask_seed：2026（全部一致）
复本数：5（全部一致）
随机条件数：105
位置条件数：27
mask哈希不一致数：0
审计结论：通过
```

| 缺失模态组合 | R_MAE | 相对完整输入MAE增量 | 缺失条件Macro-F1 |
|---|---:|---:|---:|
| text | 0.638907 | 0.034538 | 0.536642 |

### 14.5 对论文结论的修正

增强实验提高的是内部有效性和可复现性，不是模型性能。论文建议采用以下表述：

> 在统一固定缺失掩码、5个随机复本和3个训练种子的验证协议下，M0的平均R_MAE为0.624765，容量匹配对照B4为0.626377，平均差仅0.001612，且M0跨种子标准差为0.022579。M0在2/3个种子上优于B4，但该差异不具备小样本显著性证据。结果表明显式连续缺失结构带来有限且不稳定的平均收益；同时，文本缺失及其与高缺失比例的交互是最主要的性能退化来源。

不得写成：

- “M0显著优于B4”；
- “统一掩码后M0性能提升”；
- “缺失位置没有影响”；
- “附件3验证了鲁棒性”。

本增强复核只使用验证集，未重新训练，未重跑官方test，未修改附件3正式提交。
