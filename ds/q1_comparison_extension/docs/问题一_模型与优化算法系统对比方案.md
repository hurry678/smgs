# 问题一模型与优化算法系统对比方案

协议版本：`q1-comparison-1.0`

适用范围：E题问题一，兼顾问题二、三接口约束

机器配置：[configs/q1_comparison_protocol.json](../configs/q1_comparison_protocol.json)

执行状态说明：历史Git产物只完成了候选B内部比较；此前服务器缺少候选A，不能宣称A/B/C已执行。本扩展现提供候选A冻结比较包，但正式结论仍以服务器新运行产生的`preflight.json`、`version_comparison.json`、`probe_summary.json`和`validation.json`为准。

## 1. 对比目标与范围

本实验回答四个互不替代的问题：

1. 哪个方案能完整、合法、可追溯地处理附件1全部100条视频？
2. 哪个时间对齐方案与独立边界证据更一致，且不会对静音或不可观测语音伪造词时间？
3. 哪组文本、声学和视觉表示在控制数据拆分与模型容量后，具有更好的情感信息保留能力？
4. 在总附件不超过50MB、有限赛期和CPU可复现约束下，哪个方案形成更优的精度、成本与风险平衡？

比较遵循“先合法、再有效、后效率”的层级决策，不把不同量纲指标任意加权成一个分数。所有候选使用同一原视频、原文、标签、分组折、随机种子和下游探针；禁止因某个方案失败而删除样本。

### 1.1 评估维度

| 层级 | 维度 | 判断用途 |
|---|---|---|
| G0硬门 | 100条覆盖、源摘要、有限数值、合法区间、掩码、匿名性 | 任一失败则不进入正式候选 |
| G1时间证据 | 人工边界误差、独立ASR分歧、VAD重叠、静音伪对齐率 | 评价跨模态对齐，不等价于情感预测 |
| G2表示效用 | Accuracy、Macro-F1、MAE、Pearson | 评价冻结表示中可供简单模型利用的信息 |
| G3鲁棒性 | 缺失状态、异常样本、跨平台漂移、冷/热缓存一致性 | 评价复杂场景下可用性 |
| G4效率 | 墙钟时间、CPU、峰值内存/显存、模型与特征体积 | 决定竞赛可执行性和提交预算 |
| G5解释性 | 原文字符、音频时间、原始帧PTS双向映射 | 保证与问题三接口兼容 |

### 1.2 选择标准

1. 所有G0硬门必须通过。
2. 有人工边界时，以人工端点P90和短语IoU为第一判据；没有人工真值时，只报告模型间一致性，不写“准确率”。
3. 在G1不显著退化的候选中，比较G2的分组嵌套交叉验证结果。
4. 建立“边界质量、Macro-F1、Pearson、耗时、峰值内存、包体”的Pareto前沿。
5. 候选性能差异处于一个标准误内时，选择体积更小、CPU可复现、缺失语义更明确的方案。
6. 不允许下游探针的小幅增益覆盖静音伪对齐、源映射缺失或数据泄漏等硬缺陷。

## 2. 候选模型与优化算法

### 2.1 A：当前审计版，首选方案

**全称：MFA主边界的轻量BERT—可解释声学—MediaPipe几何特征短语级多模态对齐模型。**

- 文本：`google/bert_uncased_L-2_H-128_A-2`，两层Transformer、128维隐藏状态；完整原文编码后按字符范围聚合到短语。
- 语音：13维MFCC、log-RMS、ZCR和pYIN基频，共16维；按真实窗支持区间与短语的交叠长度逐维加权。
- 视觉：MediaPipe Face Landmarker眼口几何量6维；使用原始帧PTS，缺失和主体歧义显式记录。
- 对齐：Montreal Forced Aligner 3.4.1及英文声学模型、词典和G2P；词边界按标点、停顿、词数、时长形成短语。
- 证据：stable-ts、Silero VAD和无原文提示Whisper只作审计，不回填主边界。
- 异常：数字静音或主边界不可用时输出唯一`clip_context`，不宣称逐词时间。

理论基础：BERT的双向自注意力建模上下文语义；MFCC近似短时谱包络；pYIN通过概率化基频跟踪表达韵律；人脸关键点比像素纹理更接近可解释的表情几何；MFA利用给定词序列和声学模型执行受约束的Viterbi强制对齐。

### 2.2 B：Git冻结版，完整备选基线

**全称：BERT-base—40维声学—Haar人脸ROI特征与能量/停顿动态规划词级对齐模型。**

- 文本：`bert-base-uncased`，12层、768维词表示。
- 语音：能量、ZCR、谱质心、带宽、滚降、平坦度、谱通量、有声概率、归一化F0、MFCC/差分/log-Mel，共40维。
- 视觉：OpenCV Haar检测最大人脸，提取框几何、Hu矩、局部统计、直方图、HOG和纹理，共90维；论文推荐`no_hog_54`。
- 对齐：20Hz工作网格，优化词内语音活动、时长适配和边界停顿奖励；满足单调、非重叠约束。
- 平滑：只在连续有效段内执行高斯平滑，正式参数`sigma=0.75`。

选择依据：它是仓库已有完整100条产物和多候选对比的独立实现，代表“更大文本模型＋更丰富手工特征＋无需外部强制对齐器”的路线。

### 2.3 C：容量增强混合版，第二备选

**全称：BERT-base容量增强与当前审计对齐/缺失协议的混合模型。**

- 只将A的128维小BERT替换为冻结BERT-base，或在训练折内拟合固定维度投影。
- 保留A的MFA主时间、真实PTS、逐维声学掩码、MediaPipe几何、静音与不可对齐分支。
- Haar只作为小脸候选框；候选还必须通过关键点或几何质量门，不能单凭矩形框视为有效人脸。

选择依据：A与B的现有比较表明，A的时间和缺失语义更可靠，B的文本容量更大。C用于判断BERT-base是否能在不牺牲A的审计能力时带来可重复的表示增益。

### 2.4 必须保留的负对照

- 文本Hash 768维：确认BERT增益来自上下文表示，而不是维度。
- 按字符/词长比例分配时间：复杂度低的时间基线。
- 均匀时间分配：检验任何语音感知对齐是否真正优于朴素规则。
- 无平滑：检验平滑是否只改善表面平稳性而损害局部情感变化。

## 3. 理论优势与潜在不足

### 3.1 数学对象

设样本转写包含\(W\)个词，音频帧数为\(T_a\)，视觉采样数为\(T_v\)。第\(j\)个公共时序项记为

\[
P_j=(C_j,I_j),\quad C_j=[u_j,v_j),\ I_j=[a_j,b_j).
\]

每个方案都必须满足\(0\le a_j<b_j\le D\)，字符与原文可逆映射，缺失值和数值零可区分。

### 3.2 时间对齐算法

**MFA。**其核心是给定词序列约束下的HMM/DNN声学解码与Viterbi最优路径。若解码图的有效状态数为\(S\)、每状态平均转移分支为\(B\)，时间复杂度近似\(O(T_aSB)\)，内存可通过逐帧动态规划控制。优势是边界由具体词音素与声音证据共同决定；不足是依赖词典、声学模型和外部环境，口音、错转写、静音时可能失败。

**能量/停顿DP。**第\(j\)个边界候选集合为\(\mathcal C_j\)，目标为

\[
\max_{b_0<\cdots<b_W}
\sum_{j=1}^{W}\left[
\alpha A(b_{j-1},b_j)-\beta\log^2\frac{b_j-b_{j-1}}{\ell_j}
\gamma Q(b_j)\right],
\]

其中\(A\)为活动得分、\(\ell_j\)为词长先验、\(Q\)为停顿奖励。复杂度为

\[
O\!\left(\sum_j|\mathcal C_{j-1}||\mathcal C_j|\right),
\]

候选半径近似为\(R\)时约为\(O(WR^2)\)。动态规划在有限候选图上得到全局最优解，不存在梯度收敛问题；但目标函数不包含具体词/音素似然，因此“收敛到最优”只表示对人工目标最优，不保证语义对应正确。

**长度/均匀分配。**复杂度均为\(O(W)\)，确定性强，但没有利用语音内容，只能作为负对照。

### 3.3 表示模型

Transformer单层自注意力复杂度约为\(O(L^2d+Ld^2)\)。BERT-base约110M参数，语义容量高但CPU推理、内存和权重体积明显高于两层128维小BERT；后者约数百万参数，更容易随50MB附件交付。两者均冻结时没有训练收敛问题，实验比较的是表示质量与推理成本。

声学提取主要复杂度为短时FFT的\(O(T_an_{\rm fft}\log n_{\rm fft})\)。A的pYIN比简单自相关F0更耗时，但输出逐维有效掩码；B的40维描述更丰富，却必须检查F0缺失是否错误地使其他维同时失效。

MediaPipe关键点包含神经推理成本，但6维几何量紧凑、可解释；Haar级联和ROI手工量轻量且可能召回小脸，但纹理易受光照、背景和非人脸结构影响，且“检测率”不等于人脸精度。

### 3.4 探针优化

冻结特征的分类探针使用带\(L_2\)正则的多项逻辑回归，回归探针使用Ridge。标准化器和正则参数只能在训练折/内层验证折拟合。凸目标在给定正则下有全局最优解，避免将深层下游网络的优化不稳定误归因于问题一特征。

## 4. 实验指标与统一环境

### 4.1 指标体系

**硬门：**样本覆盖率、源SHA一致率、有限数值率、区间合法率、缺失掩码一致率、静音伪词边界数、字符/音频/原帧可回溯率、匿名扫描命中数。

**边界：**人工端点Median AE/P90、短语IoU、独立ASR精确词匹配覆盖及端点分歧、VAD重叠、不可用率。人工标注必须来自独立听辨，不能用当前输出作参考。

**表示：**三分类Accuracy和Macro-F1、强度MAE和Pearson；同时报告均值、标准差、95%区间和每折结果。

**质量：**词元覆盖、各声学维有效率、视觉有效率、人工子集视觉误检/漏检、独立聚合重算误差。

**效率：**冷/热运行墙钟时间、CPU秒、峰值RSS、峰值VRAM、特征文件、模型权重和预计整题包体。

### 4.2 环境标准

必须记录CPU型号与核数、GPU型号与显存、RAM、操作系统、Python、CUDA/cuDNN、FFmpeg、MFA、NumPy、SciPy、PyTorch、Transformers、OpenCV、MediaPipe及模型SHA。每个候选固定线程数、随机种子和批大小。

推荐两套环境：

| 环境 | 用途 | 标准 |
|---|---|---|
| CPU基线 | 必须完成的可复现性与效率测试 | 4线程，禁用GPU，冷/热各3次 |
| GPU加速 | BERT-base/扩展视觉模型的吞吐测试 | 单卡固定型号，批大小不超过显存，报告峰值VRAM |

GPU不是A的必要条件。只有C的大BERT或未来深度视觉表示在CPU吞吐不足时才启用GPU；所有候选仍需提供CPU降级路径。

## 6. 实验实施步骤与时间

### 阶段0：冻结协议与输入，1小时

核对附件1—4、Git提交、当前版代码/模型摘要；生成`preflight.json`和执行计划。先冻结候选和指标，再查看比较结果。

### 阶段1：冒烟与契约验证，1—2小时

选短、中、长、静音、无脸、多人各类共6条；检查每个候选的字段、掩码、时间、异常分支、日志和资源统计。任何G0失败先修复，不进入全量。

### 阶段2：全量提取与边界评价，3—6小时

三方案处理全部100条。A、B共享同一独立ASR匹配子集；有条件时对分层抽取的20条执行双人边界标注。人工子集至少覆盖静音/不可对齐、ASR零匹配、最大模型分歧、短/中/长、低视觉有效率和多人场景。

### 阶段3：表示探针，2—4小时

以`video_id`分组做5外层×3内层嵌套验证，重复5组种子。内层只选择正则强度或固定投影维度；外层一次性报告性能。附件1标签只在该阶段使用，不反馈修改提取边界。

### 阶段4：效率、稳定性与包体，1—2小时

CPU冷/热各3次；可选GPU运行同一配置。监控墙钟、RSS/VRAM和输出摘要。相同输入和版本重复两次，要求结构与状态完全相同；允许底层浮点微差，但需报告最大差。

### 阶段5：统计与论文冻结，2小时

执行配对video-cluster bootstrap、Wilcoxon和Holm校正；形成Pareto图、主表、适用性矩阵、失败案例和最终选择。原始结果只增不改，修订产生新run_id。

## 7. 数据拆分与统计细则

- 同一`video_id`的所有clip只能出现在同一外层折。
- 标准化、PCA/投影、特征选择和正则选择都在训练折内完成。
- 5个固定种子及完整折清单随结果保存。
- 分类同时报告三类支持数与混淆矩阵；回归报告总体和情感区间分层误差。
- 候选比较基于完全相同的外层测试样本，报告逐样本差。
- 人工边界采用两位标注者；先报告标注者间差异，再冻结共识，不能让开发者根据待评算法输出修改参考。
- 现有Git十次重复探针只作探索性先验；确认性结论使用本协议新冻结的外层结果。

## 8. 结果记录规范

每次运行必须有：

- `run_id`、开始/结束时间、Git提交、脏工作树状态；
- 数据、代码、配置、模型和输出SHA-256；
- 完整命令、环境、随机种子、线程数、设备；
- 每样本状态、耗时、警告、错误堆栈；
- 每折训练/验证/test分组ID和指标；
- 失败样本不得从分母删除，须记录`failed`、固定回退或未完成；
- 自动结果、人工修订、独立参考分别存储。

机器字段和执行入口见[AI服务器执行说明](AI服务器执行说明.md)，论文填表见[结果分析模板](../templates/问题一_对比实验结果分析模板.md)。

## 9. 预期结论边界

实验可证明某方案在指定输入、环境和指标下更合适，不能证明其对所有数据或所有下游模型普遍最优。没有人工边界时只能比较结构合法性和模型间一致性；没有在同一外层折比较A/B/C时，不能用Git旧报告证明BERT-base优于小BERT。附件3、4无标签，不能被用于选择问题一方案。
