# 问题一方法对比与最终选型

## 结论

| 环节 | 最终选择 | 依据 |
|---|---|---|
| 文本 | `bert` | Macro-F1 比 Hash 基线高 0.0627，Pearson 高 0.2498，Holm 校正后显著 |
| 语音 | `full_40` | F1 最高且保留 MFCC、差分和频谱信息；轻量 3 维方案未形成显著全面优势 |
| 视觉表示 | `no_hog_54` | 相对 `full_90` 的 F1 不降，Pearson 提升 0.0548 且 Holm 校正后显著 |
| 视觉采样率 | `5 fps` | 10 fps 的 F1 提升不显著，Pearson 未提升，成本约翻倍 |
| 对齐 | `full_dp_20` | 无候选在多重校正后显著更优；其停顿结构和时长适配最均衡 |
| 平滑 | `sigma=0.75` | `sigma=1.0` 的 F1 增益不显著且 Pearson 显著下降 |

正式 NPZ 仍保存完整特征超集：BERT 768 维、语音 40 维、视觉 90 维。`no_hog_54` 的索引为 `0..48` 与 `85..89`，是从正式视觉特征确定性切片得到的下游推荐视图，不改变原始特征归档，也不需要重跑问题一特征提取。

## 配对统计

同一次重复内所有候选使用相同的 `video_id` 分组折分。重复折之间并非独立样本，因此表中的 `p` 值只用于方法选型，不能写成正式泛化显著性。

- `bert` 相对 `hash`：Macro-F1 平均差 `+0.0627`，Pearson `+0.2498`，10/10 次胜出。
- `no_hog_54` 相对 `full_90`：Macro-F1 `+0.0033`（不显著），Pearson `+0.0548`（Holm 校正后显著）。
- `compact_38` 相对 `full_90`：Macro-F1 `+0.0310`（Holm 校正后显著），Pearson `-0.0328`（不显著）；与 `no_hog_54` 相比 Pearson 低 `0.0876`。
- `full_dp_40` 相对 `full_dp_20`：Macro-F1 `+0.0046`、Pearson `+0.0053`，均未通过 Holm 校正；计算耗时约为 3 倍。
- `energy_voiced_f0_3` 相对 `full_40`：Macro-F1 `-0.0120`、Pearson `+0.0060`，均不显著；MAE 较低但特征覆盖不足。
- `sigma_1p0` 相对 `sigma_0p75`：Macro-F1 `+0.0027`（不显著），Pearson `-0.0008`（统计显著但数值可忽略）。
- `10 fps` 相对 `5 fps`：Macro-F1 `+0.0136`（不显著），Pearson `-0.0136`（不显著），存储与计算约翻倍。

## 决策边界

1. 对比实验是方法选型探针，不是问题一正式预测模型，也不是问题二结果。
2. `length_weighted` 的时长适配较高，但没有使用语音能量、有声概率和停顿结构，因此不能据此声称其真实词边界更优。
3. 视觉线性探针的 Pearson 仍为负，只能说明当前简单探针下视觉表示较弱，不能推出视觉模态对情感预测无用。
4. 如问题二验证显示视觉强度预测优先，可回退到 `compact_38`；如音频带宽或显存成为瓶颈，可对照 `energy_voiced_f0_3`，但须作为问题二消融重新评价。
