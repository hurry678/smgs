## 2. 发现的问题

v2 的 `top_support_fidelity` 对连续模式先执行

```python
top = max(continuous_candidates, key=class_delta)
```

随后取 `top.window_index` 对应的一次随机连续或点散控制。控制组没有独立取
最大值。因此比较混合了两种效应：

1. 连续窗口是否具有更强的结构性证据；
2. 连续组被择优、控制组未被择优产生的选择偏差。

最小反例：

```text
continuous = [0, 1]
control    = [1, 0]
```

两组候选集合完全相同。v2 先选 continuous 的索引 1，再比较 control 的索引
1，得到差值 `1 - 0 = 1`；对称 top-vs-top 应为 `1 - 1 = 0`。

## 3. v2 结果中的证据

完整验证集的所有窗口比较：

| W | continuous - random 均值 | 95% CI | continuous - scatter 均值 | 95% CI |
|---:|---:|---|---:|---|
| 3 | 0.0001575 | [-0.0019882, 0.0021623] | -0.0011619 | [-0.0031681, 0.0008858] |
| 5 | -0.0001244 | [-0.0032497, 0.0030489] | -0.0024098 | [-0.0056863, 0.0008625] |
| 10 | -0.0028677 | [-0.0076851, 0.0020694] | -0.0031072 | [-0.0080409, 0.0019002] |

三种尺度的普通窗口均值没有显示连续窗稳定优于两类控制；但单边 top 指标给出
约 0.07–0.11 的正差且三个尺度全部通过门槛。这种数量级反差与代码中的单边
择优一致。因此 v2 的 W=3 不能直接作为最终尺度结论。

## 4. v2.2 修正

对每个样本、模态、模式分别计算

\[
q_{p,j}=\Delta_{c,p,j}/|W_{p,j}|
\]

并独立选择

\[
q_p^\star=\max_j q_{p,j}.
\]

之后比较

\[
q_\mathrm{continuous}^\star-q_\mathrm{random}^\star,\qquad
q_\mathrm{continuous}^\star-q_\mathrm{scatter}^\star.
\]

三种模式拥有相同候选数量；窗口末端实际预算不足时也通过分母校正。差值继续
按 `video_id` 聚类 bootstrap 5000 次。

选择器强制要求：

```text
comparison_schema = q3v2.2-symmetric-top-support-v1
control_selection_symmetric = true
```

旧报告会被拒绝，不能混入新冻结流程。
