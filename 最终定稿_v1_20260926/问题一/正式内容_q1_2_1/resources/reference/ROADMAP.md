## 1. 路线固定与最小交付

### 1.1 只维护这一条主线

| 环节 | 固定选择 | 唯一必要的回退 |
|---|---|---|
| 数据版本 | Q2/Q3统一采用附件2 `aligned_50.pkl`及对应专项文件 | 先修输入适配；本轮不开发非对齐版，不混用两个版本 |
| 文本输入 | 附件给定的`text_bert`三路词元输入 → `google/bert_uncased_L-2_H-128_A-2` → 128维表示 | 先修词表/预处理；必要时仅换同架构、词表已核实的权重来源。兼容性失败时暂停正式训练，不能改用不存在的768维输入 |
| Q1 | 全100条视频；短语级真实时间对齐；小BERT文本、可解释声学量、人脸几何量 | 低质量自动对齐片段人工标短语边界；保留真实时间范围和误差，不均匀摊词冒充对齐 |
| 基线B | 冻结小BERT＋每模态单层BiGRU＋掩码门控＋双任务头；原始输入训练 | 同一B模型作为主模型效果不佳时的发布回退 |
| 主模型R | 与B完全相同的网络，加入连续局部缺失增强；少量整模态遮挡用于解释子集适应 | R未通过验证比较则发布B；仍完成缺失实验并如实报告 |
| Q3 | 复用最终Q2预测器；三模态精确Shapley＋一种局部窗口遮挡 | 保持同一解释算法，缩减验证样本数；不能省略20条专项解释或伪造时间 |
| 训练规模 | 一个固定训练种子、B/R各一次主训练；小BERT默认冻结 | 显存/时间紧张时缩batch与轮数；不通过更大模型、蒸馏或新分支救火 |

正式主线只有B、R两种训练配置。统计常量和P0文本岭回归只作接口/能力诊断，不扩展为模型竞赛。输出固定使用三分类头及符号一致的强度投影，见第5节；不再并列C1—C3。

### 1.2 最低可提交成果是题面完整闭环

| 必须完成 | 可验收产物 |
|---|---|
| Q1覆盖100条、特征定义、可核验时序、全量特征提交 | 100条特征记录、时间映射、全量100行汇总、至少1个三模态对齐样例、方法/参数/日志 |
| Q2模型、训练目标及必要实验证据 | B/R对比、三分类Accuracy/Macro-F1、MAE/Pearson、缺失模态/位置/长度分析、基本错误归因 |
| Q2专项输出 | 对齐版附件3的30条极性与强度CSV，ID/文件名全覆盖 |
| Q3模型与解释 | 实际发布模型的验证指标、模态作用差异、主要参考模态、局部重要性图、典型解释卡 |
| Q3专项输出 | 对齐版附件4的20条预测与解释CSV；证据可对应真实原文、语音时间区间或视频帧 |
| 论文与复现 | 三问方法、结果与必要分析均进入正文；核心代码、权重、配置、环境和运行说明；附件≤50MB |

题面明确要求“全量原始特征文件随附件提交”和“100条样本多模态时序特征文件”。可将100条记录存入一个标准容器，不强求100个物理文件；只交汇总表和一个样例不够。缺失规律、基础指标和基本消融属于必要交付，不因缩减多种子而删除。

**交付优先级：** P0为可行性验证；P1为上表全部硬交付。P2只有在三问原型与P1-B必需验证已完成、P1-C及收尾时间已预留后才可开展，且必须在查看保留test及专项预测之前完成。P2可增加第二训练种子、点缺失等预算对照、小规模遮挡敏感性；本轮不做蒸馏、扩散、大BERT、多架构搜索、非对齐分支、完整bootstrap或复杂结构创新。

## 2. 已知事实、数据边界与统一接口

### 2.1 事实与未验证项分开

证据：[数据审计JSON](roadmap_review/data_audit.json)、[审计脚本](roadmap_review/audit_roadmap_data.py)。脚本已实际运行，包含两个专项版本的结构检查；没有训练或专项预测。

| 核查项 | 已知事实 | 执行含义 |
|---|---|---|

| 附件2对齐版 | train/valid/test＝3395/728/727；`text`为50×768，`text_bert`为3×50 | 768维`text`仅作诊断；正式B/R都用词元接口 |
| 附件3对齐版 | 30份；`test`嵌套；`audio(1,50,74)`、`vision(1,50,35)`、`text_bert(1,3,50)` | 没有raw_text也能用BERT；float32存储的词元须验证整数性再转int64 |
| 附件3未对齐版 | 30份；`audio/vision`有500位置，提供`raw_text`，没有`text_bert` | 与对齐版不是同一个文本接口；本轮仅记录，不开发 |
| 附件4对齐版 | 20份；平铺`id/raw_text/text/text_bert/audio/vision`，配套视频 | 使用`text_bert`保持预测接口一致，raw_text和视频用于证据对应 |
| 原生零特征 | train/valid视觉整段全零110/15条；视觉有语义零行421/85条，语音4/1条 | “完整条件”一律指未额外合成遮挡的原始输入；原生不可用仍需掩码 |
| 标签与划分 | 数字0/1/2对应Negative/Neutral/Positive；附件2各划分两两无同ID、同video_id交叉 | 固定题给划分，标准化只拟合train |
| 原素材重合 | 附件1与附件2同样本重合：train 11、valid 0、test 7 | 用11条训练重合素材验证映射；不能声称验证集有原视频回看结果 |

`text_bert`是`input_ids/attention_mask/token_type_ids`，不是连续768维向量。BERT词表兼容性尚未验证；候选CLS/SEP编号相同不等于词表已兼容。历史`text＋岭回归 MAE=0.7091`来自另一表示空间，保留为诊断参照，删除MAE≤0.74合格线。

### 2.2 数据使用边界

1. Q2/Q3可学习参数、标准化统计只由附件2 train产生；模型与超参数选择使用valid。test保留到模型和规则确定后一次评价，不反向调参。
2. 附件3/4前期只核查接口、取值合法性、零值表示及素材配对；不利用专项缺失分布调整遮挡比例，不根据专项内容选择情感模型。训练协议来源于题意及train/valid。
3. 附件3的全零区间统计如用于排查适配器，应标为“可见零值/候选缺失”，排除填充和特殊位置，并保留无法区分的状态；不能由30条专项样本推定官方生成分布。描述统计留到模型规则确定后的最终报告阶段，不参与选模。
4. Q3时间映射方法主要在11条训练重合素材开发。附件4可提前核对ID、原文/视频是否匹配以及字段可读性；正式归因、证据排序和逐条时间定位在预测器及解释规则确定后完成。确需提前播放时仅作配对核查，不据此改模型或筛选情感规则。
5. Q1按题面覆盖100条，不能删改原样本和标签；其中与test重合的7条不向Q2/Q3反馈标签，优先选训练重合样本展示案例。Q1自提取特征不替换Q2/Q3题给特征。
6. 题面允许通用预训练模型，禁止增加外部情感数据集用于训练/优化/统计。记录工具来源、模型版本/权重摘要、许可证、核心参数及用途。AI使用要求以实际竞赛统一文件为准，不引用尚未核实的处罚原文。

### 2.3 适配器必须输出的最小对象

```text
sample_id, source_file, feature_version="aligned_50"
input_ids[50], encoder_attention[50], token_type_ids[50]
audio[50,74], vision[50,35]
position_valid[50], semantic_valid[50]
observed[3,50], ambiguous[3,50]
label_class, label_intensity   # train/valid允许用途才提供
```

- 序列骨架、填充、真实语义位置和模态观测状态分别存储。CLS/SEP参与BERT，不作为音视频观测或独立证据；`text`在填充处也非零，不能按非零判有效。
- 先用原始字段判定缺失，再标准化；音视频仅用train可观测语义行计算均值/标准差，缺失行变换后仍清零。零方差维度scale置1。
- 文本遮挡必须在BERT编码前发生：确定缺失的语义位置转换为核实词表中的`[MASK]`，保留位置并使其可参与上下文计算，但`observed_text=0`；填充attention为0。被遮挡词的raw_text、预计算text及旧隐藏状态不得进入预测。
- 有内孔的attention不能被直接当作序列终点。优先用可信长度/SEP恢复骨架；尾段无法区分缺失与填充时保存ambiguous，固定保守规则并在valid做对照，不让训练器把遮挡前真值长度传给模型。
- 合成遮挡先写成文件接口的缺失形式，再走同一适配器。训练真值遮挡仅用于核查新增删除率；部署没有的元数据不用于模型输入。关键契约检查失败先修复，不能靠静默填补通过。

## 3. 前12小时P0：先解除四项实际风险

以下为从启动实施开始的时间盒，安装和下载可与文档/编号核查并行。12小时是控制投入的上限目标，不是保证；实际剩余赛期不足时按第8节裁减，不能省略硬条件。

| 时间盒 | 工作与方法 | 必须留下的结果 | 停止/继续规则 |
|---|---|---|---|
| 0—2h | 建独立环境并开始模型下载；复用现有审计；实现最小适配器，核对30/20文件及零值/填充表示；确认材料版本 | `p0_report.md`输入部分、可读取的统一样本、训练/专项同结构烟测 | 没有合法输入就先修接口；不设计新模型 |
| 2—4h | 锁定小BERT；全train原文重分词核验词元。比较原text池化＋岭回归与冻结小BERT池化＋同样岭回归 | `tokenizer_check.json`；全valid文本回归诊断；真实权重字节/编码耗时 | 匹配失败先修预处理；无需达到旧MAE，不能以旧表示成绩替代新路线测试 |
| 4—7h | 从11条训练重合素材按时长选短/中/长3条；打通“给定位置→词/短语→音视频时间”；计算空档跑B一轮与完整valid | 3条对应表、原帧时间戳、误差和不确定性；附件4配对记录；B四指标、epoch/valid耗时和内存 | 缺少位置依据先查提取说明并人工复核；不将定位风险推迟到最终输出 |
| 7—9h | 跑3条Q1全链路；检查最长原文，不静默截断；用真实权重、3条实际特征、配置和说明做局部试包 | 三条NPZ/时间映射；耗时与字节/秒统计；`p0_trial.zip`、全量估算与假设 | 这是局部试包，不宣称已满足最终50MB；超预算先减输出冗余/压缩，不删样本 |
| 9—12h | B训练至少得到可诊断checkpoint；R跑一个缺失batch和至少一轮；实现8子集与局部遮挡烟测；形成论文目录 | `p0_report.md`完整、任务队列、B/R实际计算路径和解释目标、`paper/draft.md`骨架 | 输入/定位/速度/存储有证据后推进全量；未通过的风险留在P0修复，其他独立工作继续 |

小BERT兼容性核查包括：权重/词表来源、所有实际词元是否落入词表、特殊编号、lowercase、截断、补齐和token_type。对train全部样本重编码给出逐条匹配率，失败项必须分类解释；valid仅作独立核查，不能根据专项原文反推词表规则。能逐项解释的差异不盲目要求字符串处理完全相同；无法解释的ID语义不允许正式训练。

文本诊断使用同一train/valid划分、语义位置均值池化、train拟合标准化、岭系数固定10与[-3,3]裁剪，报告MAE/Pearson和耗时。它衡量更换表示的代价，不是融合机制对照；四项任务指标由实际B双任务模型计算。

吞吐计时在安装完环境后进行，性能检查先给30分钟时间盒：warm-up后计一个train epoch、全部728条valid、一个8子集解释和一个局部解释；MPS计时前后同步。记录batch、device、线程和峰值内存；数据加载、首次模型加载与稳态耗时分开。环境安装不包含在30分钟内；单个epoch超时则中止并用已处理batch估算，标记为估算。

估算使用`Σ_B,R 训练轮数×epoch实测时间＋Σ_B,R 轮数×开发评价时间＋条件数×完整valid时间＋解释样本数×解释实测时间`，再加入加载、提取、人工复核、写作和收尾。视频提取按三条中较慢的单位时长耗时估算全量。所有估算附实测范围；没有吞吐就不承诺固定总工期。

## 4. Q1固定实现：100条短语级多模态特征

### 4.1 工具与特征

| 环节 | 固定起点 | 输出与限制 |
|---|---|---|
| 解码 | ffmpeg/ffprobe；音轨16kHz单声道；保存音视频流起始偏移和原帧PTS | 同一片段相对时间轴，不能仅用帧号/fps替代真实时间 |
| 文本 | 给定转写＋P0核验的小BERT，冻结编码；按短语聚合子词表示 | 128维；长文本分块覆盖全原文，滑窗重叠去重，不受Q2的50位置上限约束 |
| 语音 | librosa；MFCC(13)、log-RMS、ZCR用25ms窗/10ms步长；基频用pYIN 64ms窗/10ms步长，初始65—500Hz | 16维；基频无声处单独掩码，单位Hz；各自窗中心按同一时间轴聚合，超出音域边界作异常记录 |
| 视觉 | MediaPipe Face Landmarker；按真实PTS约5fps采样；固定主脸选择规则 | 归一化几何6维：双眼开合、嘴开合、嘴宽、左右嘴角相对鼻部位置；定义所用关键点及尺度，不臆称情绪概率 |
| 时间对齐 | stable-ts使用Whisper `tiny.en`的给定转写对齐功能，模型CPU起步；只输出时间不改原转写 | 以停顿/短语合并成可核验区间；未验证前不承诺逐词精度 |

工具/API版本在P0安装成功后锁定；上表不是已验证环境清单。对齐工具在P0限定时间内无法运行，则统一采用人工短语时间标注表（100条总时长由ffprobe核查），继续使用相同提取、聚合和读取接口，不再试装多套大型对齐框架。人工标注脚本支持断点续作；自动与人工来源逐条登记。

脸部默认选择最大有效脸，之后按位置连续性跟踪；多人、换人或无法确认主说话者标歧义并回看。检测失败不伪造中性表情。关键点不可用时使用缺失状态并记录实际有效率；大量失败先修解码/检测，不以100个空容器宣称特征提取成功。不做身份识别和微表情能力声明。

### 4.2 数学对象与输出

每个短语`I_j=[a_j,b_j)`对应原文字符范围，满足`0≤a_j<b_j≤D`、时间有序。对有效音频窗`J_k`，逐维按时间重叠加权：

`x_j = Σ_k |I_j∩J_k| M_k x_k / Σ_k |I_j∩J_k| M_k`。

`M_k`为该维是否有效，分母0则该维缺失。视频聚合落在区间内的有效采样帧，保存其PTS/原帧索引；区间内没有采样帧就标无覆盖，不用远处帧替代。文本按字符/子词归属聚合；重复窗口中的词只计一次。

固定声学配置记录采样率、win_length、n_fft、hop_length、MFCC阶数与center/padding规则，不能使用库默认值而漏记实际时间偏移。视觉6维的关键点索引和归一化距离在P0写入字典后固定。

交付标准对象为短语级三模态特征，共150维（128＋16＋6）、各维有效掩码、区间和原文范围；这是Q1定义的最终自生成特征。解码波形、全部原视频帧和中间逐帧缓存不是该特征文件，无需重复打入附件。变化粒度必须写入正文，不把短语均值说成毫秒级时序。

用压缩NPZ存数值、JSONL存原词/时间/帧索引，100条可独立读取或一个容器中按ID读取。`q1_summary.csv`含100行：video_id、clip_id、原有效时长、各模态维度、短语数、覆盖率、对齐来源和异常。

自动检查全部100条：ID覆盖、有限值、范围合法、索引可重建。先人工复核P0三条及所有自动标出的异常，普通样本扩到10条属于有时间再做。论文至少1张真实对齐图；报告核验样本/边界数、边界误差中位数和90%分位数，不预设必须达到0.25秒。不准确时回标或扩大到有依据的短语范围；不能以整段视频替代所有局部证据。

## 5. Q2固定实现：同网络B/R对照

### 5.1 编码、融合与两个输出

冻结小BERT产生`H_text∈R^(50×128)`。音视频按train统计标准化，分别线性映射到128维。三模态各自乘观测掩码，与本模态观测/歧义标记拼接，输入各自的单层BiGRU（输入130维、每方向64隐藏维）。保留缺失位置占位，不压缩时间轴；只去除已证明的尾部填充。时序表示不在缺失处当作真实观测直接聚合。

对至少有一个模态可用的语义位置，普通门控为：

`r_mt = u_mᵀ tanh(W_m h_mt + b_m)`，

`w_mt = O_mt exp(r_mt) / Σ_n O_nt exp(r_nt)`，`z_t = Σ_m w_mt h_mt`。

用数值稳定masked softmax；三模态全缺失的位置跳过池化。对其余有效位置**固定均值池化**得到`z̄`，不再增加结构打分或时间注意力模块。全样本无证据时返回train类别频率和强度中位数。普通门控不是校准可靠概率，Q3贡献另算。

输出`p=softmax(W_c z̄+b_c)`，`s_raw=3 tanh(w_sᵀz̄+b_s)`，训练损失：

`L = CE(c,p) + Huber(y,s_raw; δ=1)`。

最终分类`ĉ=argmax p`；发布强度固定为：

- `ĉ=Neutral`：`s_pub=0`；
- `ĉ=Positive`：`s_pub=max(10^-4,s_raw)`；
- `ĉ=Negative`：`s_pub=min(-10^-4,s_raw)`。

保存原始强度，记录符号冲突率、投影比例和投影前后MAE，主要指标使用实际发布值。该规则保证CSV含义一致，不保证MAE必然改善；本轮不增加阈值搜索或更多输出头。B/R采用同规则，CSV至少保留6位小数。

### 5.2 两种训练配置和资源回退

| 配置 | 输入分布 | 用途 |
|---|---|---|
| B | 100%原始输入（保留原生缺失） | 基线、可直接部署的回退 |
| R | 50%原始、45%连续局部遮挡、5%整模态遮挡；每个样本每次只前向一种版本 | 主模型；少量整模态遮挡用于Q3子集输入适应 |

R局部遮挡：从7种非空模态子集均匀抽取，从`{0.1,0.3,0.5}`等概率选区间比例；被选模态在共同语义轴使用同一个连续区间，位置均匀随机。整模态遮挡只选6种真子集，保留至少一种模态；原生缺失导致全空时走先验。5%为内部默认值，不来自附件3统计。

语义长度`L≥2`时`k=min(L-1,max(1,round(ρL)))`，`L≤1`不合成局部遮挡并单列。记录名义比例、真实新增删除率、总不可用率；不能将原本已为零的位置算作新增删除。标准化与BERT之前写入遮挡，原词不可从缓存恢复。

固定seed=2026，B/R同初始化、shuffle、train样本数量和最大更新预算。AdamW，任务层学习率`10^-3`、weight_decay=`10^-2`、dropout=0.1、batch=16、最多20轮、早停耐心3次；BERT保持eval、无梯度。根据P0实测一次性确定两者共同的最大轮数并写入配置。

内存不足先batch降为8，再降4；MPS不支持所需操作或实测慢于CPU时统一改用CPU，避免跨设备来回搬运。速度不足缩减共同轮数，不减少训练样本或正式valid覆盖；实际早停轮数分别记录，不将不同训练步数表述为严格相同。每轮不运行完整大矩阵，使用下一节开发条件早停。冻结编码器且输入完全相同时才可缓存，缓存键包括词元/attention、权重和掩码；文本遮挡变化必须重编码。

若P0新文本路线差于历史text，不直接扩BERT：先查输入/权重/池化，再看相同表示上的有效训练。B/R均不如统计底线时进入正确性诊断；不能把修接口失败解释成创新未成功。

### 5.3 必做20条件验证，替代原大矩阵

全部正式评价覆盖728条valid；每个随机条件固定一个掩码复本。由ID、条件、seed的稳定摘要生成，B/R使用同一份；训练掩码另加epoch以覆盖不同位置。

| 组 | 条件 | 数量 |
|---|---|---:|
| 原始 | 不额外遮挡 | 1 |
| 模态×长度 | 3种单模态 × ρ={0.1,0.3,0.5}；均在中部施加连续段 | 9 |
| 位置 | 3种单模态 × ρ=0.3 × 开头/结尾 | 6 |
| 联合缺失 | 3种双模态＋三模态 × ρ=0.3；固定随机连续段 | 4 |
| **总计** | 每个checkpoint `20×728=14,560`次样本前向 | **20** |

中部起点固定为`floor((L-k)/2)`，开头为0、结尾为`L-k`。位置组数量为**6**；中部直接复用“模态×长度”组ρ=0.3的3条件，不重复计数。这样长度分析固定在中部，位置分析固定ρ=0.3，避免两因素一起变化；不声称覆盖全部交互。短序列三个位置可能重合，报告其数量而不视为独立证据。

B/R两模型最终矩阵共29,120次样本前向。不是逐样本串行调用，可batch推理。每轮开发只用固定128条valid（按标签分层一次选定）的4条件：原始＋三种单模态ρ=0.3中部，共512次样本前向；它仅用于早停，最后两模型都运行全728条矩阵，不能把开发子集指标当最终结果。

主要报告四指标及其方向：Accuracy↑、Macro-F1↑、MAE↓、Pearson↑。Macro-F1固定三类，零分母处理明示；常量输出Pearson为不适用。另报混淆矩阵、每类召回、中性表现、原生全零视觉子集和代表错误，不能推断零特征的物理原因。

在同一验证协议上固定内部选择分数：

`J = 0.5×(MAE_raw_input/6 + 1−F1_raw_input) + 0.5×mean_19(MAE_condition/6 + 1−F1_condition)`。

此处`raw_input`指未额外遮挡条件，MAE使用发布强度；6为强度范围总宽度，不是经验调参值。J只用于有限候选选择，不是官方评分或显著性检验。早停用同公式将19条件换为3个开发缺失条件。最终选J较低者，数值并列优先B；同时完整展示四指标，若出现分类/回归互有升降只能报告权衡，不能声称全面优胜。不设未经依据的MAE合格线。

必做消融由B/R输入增强开关构成，支持“这一组合训练策略是否有效”。它不能将收益单独归因于连续结构或整模态训练。只有P1-B已完成、最终交付预算充足且尚未查看test/专项预测时，才增加同预算点缺失训练或R去5%整模态训练对照，并据此增加相应主张；对照采用相同更新步数。

缺失长度以实际位置数及占语义长度比例报告；缺少全量逐词时间时不转换成秒。固定L的单段长度由ρ决定，不能声称独立辨识了长度与比例。时间长度若可在有映射的小样本上计算，只作案例说明。

## 6. Q3固定实现：真实输出的归因与素材对应

### 6.1 先建立可验证的映射方法

对应链条为：题给特征索引 → 已核实词元/原词范围 → 转写中的短语 → 原音轨时间和视频PTS。BERT字符偏移、CLS/SEP、同词子词复制、50位置截断都必须解释清楚；句子尾部未进入模型的内容不能列作模型证据。

P0三条训练重合素材验证该链。强制对齐只证明“词→时间”，不能自动证明“题给音视频位置→词”。结合题面对齐位置定义、实际占位/重复规律和可取得的原提取说明核实；若只能证明词组级映射，输出有依据的词组时间范围。原规则确实无法核实就列为硬问题继续修复，不能用均匀插值、无依据关键帧或仅文字解释宣称三模态定位完成。

预测器确定后，附件4全部20条按相同方法定位；可先批量生成完整词/短语映射，再叠加贡献选出的区间。自动失败片段人工按原文校时间；人工不改变贡献排序，也不能补造未知特征索引含义。允许输出支持证据不稳定的真实状态，但不能用20条空证据视为满足题意。

### 6.2 只用一种解释方法

固定最终完整输入预测类别`c*`。第一目标为`v_c(S)=p_c*(x_S)`，第二目标为实际发布强度`v_s(S)=s_pub(x_S)`；枚举三模态的8个子集，一批预测同时得到两个目标。

`φ_m = Σ_{S⊆M, m∉S} |S|!(2−|S|)!/3! × [v(S∪{m})−v(S)]`。

对两个目标分别检查`Σ_m φ_m = v(M)−v(∅)`。缓存8个子集的同一组输出后用float64算归因；容差用`atol=10^-5, rtol=10^-5`起步，先排非确定性、重复前向不一致与实现错误，再按实测精度说明调整，不能用放宽容差掩盖错误。

遮挡复用Q2适配器，文本必须编码前删除；重算观测、时序与门控。统一保留位置骨架和合法特殊词元，空集走无证据先验，解释的是给定位置骨架的模态内容影响。全部是对模型与遮挡基线的归因，不是现实因果效应。

CSV主模态定义为对`c*`正贡献最大的模态；没有正贡献时填“无明确支持模态”，另给绝对影响最大的模态及贡献符号。绝对作用比例`|φ_m|/Σ|φ|`不是支持概率；总贡献近零时比例填空并给原因，并列时不强行指定唯一主模态。发布强度贡献另列，不能拿分类贡献代替强度解释。

局部窗口固定为连续2个原词、步长1，各模态均计算

`Δ_m(W)=p_c*(x)−p_c*(mask_m,W(x))`。

同词所有子词一起处理；不足2词用实际长度。正值支持、负值反对；展示最高正贡献的不重叠窗口，最多3个。若没有正贡献，报告“无稳定支持窗口”并保留主要反证。图显示正负分布；重叠窗口不直接求和为模态Shapley，合并后实际重新遮挡求贡献。

### 6.3 最小验证和输出

Q3基础四指标覆盖全部728条valid；共享模型时明确引用同一原始条件结果。解释实验仅固定12条valid，按真实三类各4条预先抽取，不根据解释美观筛选；另用3条训练重合素材验证视频回看，两种验证来源分开报告。

12条做模态归因、局部排名、等词数随机遮挡对比，以及一个20%证据预算的联合删除/保留检查。预算在主要支持模态的原词位置并集上计算；其他模态保持原样，随机对照同样处理，同词子词一起操作。无主要支持模态时记录不适用。单窗口“删最高分下降最大”部分来自定义，不能单独证明忠实；记录联合结果、失败与原生缺失，有限样本不称统计显著。

局部归因成本在P0实测，8子集只占小部分。算力不足时仍给20条专项完整模态贡献与全部局部扫描；优先删除P2和扩大验证计划。最终至少展示1张解释卡、主模态局部重要性图及三模态对比，正文汇总20条结果，CSV包含实际摘要和定位，不只放JSON路径。

## 7. 包体、复现与提交检查

### 7.1 用实际字节建立预算

不再规定“Q1只能8MB”。初始参考：约4.4M参数的小BERT，FP32约17.6MB，实际下载权重可能含多余预训练头；只保存推理必要的BertModel state和配置后实测。B/R只打包最终发布的一套融合权重，BERT共享；其他实验checkpoint留本地。

Q1基础数值量可按`Σ_i n_phrase_i × 150 × 4字节`估算，另加掩码、原文映射、索引和压缩开销。用P0真实三条估计只是早期预警；全量完成后实际压缩测量。原素材、波形、逐帧图片和可重建中间缓存不重复入包。

P0先做局部试包；Q1全量完成及预测模型确定时再做正式试包。目标留余量，最终附件按≤50,000,000字节保守检查；若官方另有打包口径按其模板执行。优化顺序：去重复/缓存 → 压缩数组与文本 → 只保留必要推理权重 → 验证FP16存储。压缩参数后重算输出/解释；不能删100条特征或省略必要参数来满足体积。

### 8.2 不预设还有100小时

启动时记录实际剩余`R_total`小时。预留收尾时间`F=min(R_total/3, max(4小时,0.15R_total))`，其余根据P0实测任务队列估算；该公式是调度默认值，不是比赛规则。P0后重新记录剩余`R_left`，若预计P1＋F超出R_left，立即执行下面削减顺序，不等待固定“第75小时”。

1. 不做全部P2，包括多种子、点缺失训练、替代解释基线及结构创新；不新增架构。
2. B/R采用相同较少训练轮数，早停；保留全部train及728条正式验证，batch依据内存调整。
