# 第一问特征字典与存储契约

数值模式版本：q1-2.1；验收政策：q1-acceptance-4（2026-09-24）。数值定义由`configs/q1.json`、`src/modalities.py`、`src/alignment.py`和`src/automatic_alignment.py`共同固定。所有时间均为秒，以原片段容器起点为零；帧PTS另外保留容器原始值。常规粒度为短语；语音边界不可观测时为整段`clip_context`。

## 1. 150维特征

| Python列范围 | 维数 | 名称 | 定义/单位 | 有效性 |
|---|---:|---|---|---|
| `0:128` | 128 | 小BERT语义表示 | 冻结两层、128隐藏维的最后层子词表示，短语内唯一子词均值 | 短语有已覆盖子词时有效 |
| `128:141` | 13 | MFCC 0—12 | 40通道Slaney Mel功率谱→dB→正交DCT-II前13系数，含第0系数 | 有实际音频窗覆盖且值有限 |
| `141` | 1 | log-RMS | \(\ln(\max(\sqrt{\frac{1}{400}\sum y_n^2},10^{-10}))\)，输入为归一化PCM波形 | 有400点窗覆盖 |
| `142` | 1 | ZCR | librosa零交叉率，阈值0、`zero_pos=True`，无单位 | 有400点窗覆盖 |
| `143` | 1 | 基频 | pYIN估计，Hz，65—500Hz | pYIN有声且数值有限；无声处缺失 |
| `144` | 1 | 眼组A开合 | 关键点`[33,160,158,133,153,144]`眼纵横比 | 区间内存在有效主脸 |
| `145` | 1 | 眼组B开合 | 关键点`[362,385,387,263,373,380]`眼纵横比 | 同上 |
| `146` | 1 | 嘴开合 | `dist(13,14)/dist(33,263)` | 同上 |
| `147` | 1 | 嘴宽 | `dist(61,291)/dist(33,263)` | 同上 |
| `148` | 1 | 嘴角61相对鼻高 | `(p61-p1)`在脸部向下纵轴上的投影，除以双眼外角距离 | 同上 |
| `149` | 1 | 嘴角291相对鼻高 | `(p291-p1)`在脸部向下纵轴上的投影，除以双眼外角距离 | 同上 |

人脸点坐标先从MediaPipe归一化图像坐标转为像素坐标，避免视频宽高比引入距离畸变。脸部横轴从33指向263；纵轴取其法向量并定向为图像向下，从而降低平面内头部旋转对嘴角高度的影响。眼纵横比对六点\((a,b,c,d,e,f)\)定义为 \((\|p_b-p_f\|+\|p_c-p_e\|)/(2\|p_a-p_d\|)\)。A/B以索引为准，避免自拍镜像导致解剖左右误解。6维量不等于情感概率，也不构成身份识别。

视觉质量门要求双眼外角像素距离至少12，双眼纵横比分别不超过1.0，嘴开合不超过0.6，嘴宽不超过1.0，两侧嘴角相对鼻高绝对值不超过1.0。任何一项失败时，原始几何量只留在中间审计文件，最终值置0、掩码为假，并记录`invalid_face_geometry`。这些阈值只用于拦截分母塌缩、严重侧脸和异常关键点，不代表情感阈值。

小BERT维度不具有单独的明确物理语义，只称语义表示；声学和视觉量的情感预测贡献尚未在这套150维特征上实证。Q2/Q3使用附件2，其结果不能直接作为本套特征有效性的证明。第一问不以标签拟合或赋予情绪类别。

## 2. 时间与聚合

音频采样率16000Hz、单声道。MFCC/RMS/ZCR窗长400（25ms）、步长160（10ms），`center=False`，不做边缘补齐；第\(k\)窗支持区间为音轨偏移加\([160k/16000,(160k+400)/16000)\)。MFCC的`n_fft=400`、周期Hann窗、功率2、`n_mels=40`、`fmin=0`、`fmax=8000`、`htk=False`、`norm=slaney`。功率转dB使用`ref=1.0`、`amin=1e-10`、`top_db=80`，DCT-II、正交归一化、`lifter=0`。`top_db`相对本条音频的最大dB截底，不使用跨样本统计。

pYIN窗长1024（64ms）、步长160（10ms）、`center=False`、无声填缺失；其他参数为`n_thresholds=100`、`beta_parameters=(2,18)`、`boltzmann_parameter=2`、`resolution=0.1`、`max_transition_rate=35.92`、`switch_prob=0.01`、`no_trough_prob=0.01`。其支持区间单独保存，不能复用25ms声学窗的中心。频率边界1%范围内的有声估计另计异常数量，未根据情感结果改音域。

对短语区间\(I_j\)与音频窗\(J_k\)，逐维计算

\[
x_{jd}=\frac{\sum_k|I_j\cap J_k|M_{kd}x_{kd}}{\sum_k|I_j\cap J_k|M_{kd}}.
\]

分母为0时置数值0、掩码为假。短语间停顿不会均匀摊入每个词。

文本向量先对完整转写编码，故是定位于短语、含整句上下文的表示。声学窗可能跨短语边界，交叠加权只决定已提取窗特征的归属，不剔除窗外信号的影响。时间范围不是严格的信息依赖范围。

视觉每次选择距离上一选中帧至少0.2秒的下一实际帧，因此帧率不高于约5fps，变帧率素材按PTS自然变化。逐帧解码数量必须等于ffprobe的帧数量。每个短语只使用PTS落在区间内的采样帧，逐维对有效几何量取均值；区间内无有效帧则缺失。全帧检测失败时，使用同一个Face Landmarker及相同阈值，对中心和四角的固定60%宽高裁剪区域进行一次多尺度回退；映射回原图后按脸中心去重，并记录`face_crop_fallback`。该规则源于零检出异常的有限诊断，不改变特征定义。检测最多3张脸，第一帧选择最大框，其后选离上一主脸中心最近的脸；多人或中心移动超过归一化图像距离0.35时标记歧义，不推断主说话人身份。

给定文本以MFA 3.4.1和`english_mfa` 3.1.0声学模型执行主对齐，必须将标准化词无损映射回原文字符。按标点、至少0.3秒间隔、累计8个对齐词或已达4秒时长结束一组。4秒是分组触发值，不是严格上限。若分组短于0.08秒、词速超过8词/秒或零时长词比例超过20%，则确定性地并入时间上最近的相邻组并标记`automatic_quality_merge`。

stable-ts 2.19.1对同一原文给出第二组端点，Silero VAD 6.2.2给出语音活动区。逐端点绝对差、短语VAD重叠率和A/B/C等级是跨算法一致性证据，不是对人工真值的误差。第二组区间只有有限、非负且严格正长时才计入`endpoint_count`；缺失或退化时`secondary_status=missing_or_nonpositive_span`、`absolute_difference_s=[]`，样本记C级。`secondary_endpoint_coverage`报告实际有效覆盖，`secondary_evidence_accounted`报告每个短语是否都有明确证据状态。自动协议要求主边界通过字符/时间/质量检查且第二证据状态齐全，不能把缺失端点算作第二模型确认。A/B阈值分别为全部有效端点分歧P90不超过0.2/0.5秒，其他为C；任一第二区间缺失也为C。

独立模型核验使用Whisper base.en在不输入原文提示的情况下自由识别，识别结束后才作原词匹配。`reports/boundary_audit.json`记录每条识别文本、词编辑比、可比短语和端点分歧；它不修改`phrases`、NPZ或人工参考值，不参与特征模型训练。

若数字静音导致音频缺失，生成唯一\(I=[0,D)\)的`clip_context`，文本和视觉照常聚合，音频16维置0且掩码全假。若音频信号存在但MFA失败且VAD无语音区，同样生成整段上下文，但保留16维音频的真实整段聚合与掩码。两者的`speech_alignment_available=false`，不能解释为逐词语音边界。

## 3. 最终NPZ对象

每个文件为 `outputs/features/{video_id}$_${clip_id}.npz`；可用 `numpy.load(..., allow_pickle=False)`独立读取。

| 字段 | 形状/类型 | 含义 |
|---|---|---|
| `features` | `(P,150)` float32 | 短语或整段上下文的最终数值 |
| `valid` | `(P,150)` bool | 各维有效掩码；零值不自动等于缺失 |
| `intervals` | `(P,2)` float64 | 左闭右开时序单元范围 |
| `char_ranges` | `(P,2)` int32 | 原文Unicode字符左闭右开范围 |
| `sample_id` | Unicode标量 | `video_id$_$clip_id` |
| `duration_s` | float64标量 | ffprobe容器时长 |
| `text_token_ids` | `(T,)` int32 | 全原文唯一语义子词，不含CLS/SEP/PAD |
| `text_token_offsets` | `(T,2)` int32 | 每个子词在原文中的字符范围 |
| `sampled_frame_indices` | `(F,)` int32 | 按显示顺序从0开始的原帧索引 |
| `sampled_frame_pts` | `(F,)` float64 | 对应原始PTS |
| `alignment_available` | bool标量 | 是否存在最终时间序列项；当前100条均为真 |
| `alignment_quality_passed` | bool标量 | 当前时间区间是否通过可计算的质量硬门；不等于人工认可 |
| `speech_alignment_available` | bool标量 | 是否存在可解释为语音事件的词/短语级边界 |
| `audio_observed` | bool标量 | 音频模态是否可观测；数字静音分支为假 |
| `granularity` | Unicode标量 | `phrase`或`clip_context` |
| `schema_version` | Unicode标量 | `q1-2.1` |

每条文件按真实短语数变长存储，不含跨样本填充。后续模型组batch若补零，必须另存真实长度和位置掩码，不能把补零作为真实短语。

## 4. 映射、汇总与中间产物

`outputs/alignment.jsonl`一行一条样本，包含完整原文、源视频相对路径、音视频偏移、词时间、短语范围、子词索引、对应原帧索引及PTS、置信度、异常标记和提取耗时。JSON中`phrases[j]`、NPZ中第`j`行以及汇总中的短语计数直接对应。

`phrases[j].visual_observation_state`区分`observed`（有有效观测）、`observed_with_subject_ambiguity`（有观测但主体不确定）、`sampling_no_coverage`（区间内未采到帧）、`no_reliable_face_detected`（没有可靠脸检出）、`detected_geometry_rejected`（候选几何未通过）。这些状态解释检测及采样结果，不直接证明物理上无人；后三类保留视觉缺失掩码。

`q1_summary.csv`为100条样本的提取汇总。`phrase_time_coverage`为短语时长总和/原时长，未覆盖区间原因须核验，不能全部断言为停顿；不等于对齐准确率。`text/audio/vision_valid_rate`为相应短语特征元素有效比例；`frame_face_valid_rate`为有效脸采样帧数/所有采样帧数，二者分母不同。`human_annotated`表示导入过人工修订；旧字段`human_reviewed`不再用于验收，不能据它判断是否批准。

`outputs/acceptance.jsonl`是一行一条的正式验收记录，与具体NPZ的SHA-256绑定。当前状态为97条`aligned_auto_accepted`、1条`clip_context_speech_unavailable_accepted`和2条`clip_context_audio_missing_accepted`。人工修订仍可进入`aligned_human_approved`或`manual_reaggregated_awaiting_approval`。自动词/短语/质量分别保存于`automatic_words/automatic_phrases/automatic_alignment_quality`；当前结果使用`phrases/alignment_quality`。

`intermediate/samples/{id}/`保留原生声学窗及其支持区间、逐采样帧6维量/脸数/歧义/框、去重子词表示、原始自动对齐JSON。`intermediate/audio/`为解码波形，`intermediate/probes/`为原流信息和全部帧PTS。它们用于验证、回标和重建，不属于提交所需的最终150维特征文件。

## 5. 人工覆盖接口

`annotations/manual_phrases.jsonl`允许每条样本一行，字段为`sample_id`、`reviewer`、`reason`、`phrases`。每个短语须提供`start_s/end_s/char_start/char_end`；时间必须有限、处于素材时长内且不重叠，字符偏移须为整数，覆盖全部非空白原文。仅实际听看并标注后才填写。运行`reaggregate --sample=ID`重新聚合该样本，再运行全量`validate --diagnostic`。修订只产生`human_annotated=true`，不会自动批准或填写评价参考。

`annotations/boundary_review.csv`是唯一可编辑的主表，先导表仅为导出视图。生成列包含`current_s`、原始`automatic_s`、字符范围、来源、时长和样本/产物指纹。原文、时间、来源或NPZ变化，旧批准变为`stale`，参考值保留供核对，原行存入`.history.jsonl`。参考值必须有限、在素材内，整组起止须正长、按短语顺序不重叠；重复行不能形成批准。

可编辑状态为`pending/reviewed/approved/needs_revision`。`reviewed`只表示检查过。仅全部边界`approved`，且参考与当前输出在1e-9秒浮点容差内一致，才表示接受当前输出；不一致进入修订流程。该容差不表示听辨误差要求。硬门失败还须逐行填写`decision_note`说明覆盖理由。

`reference_source=correction`记录修订依据，差异仅作修订统计；`independent`才进入边界误差统计，并要求`reference_id`及与人工修订者不同的复核者。程序不从当前人工输出生成参考。无独立参考时，中位数/P90为`null`。

验证、打包共同执行：100条必须各有至少一个最终序列项，且通过MFA短语协议或显式`clip_context`协议；全部150维从原生数组独立重算。当前100条均自动接受，人工复核表只作可选审计。主复核表、源数据、原生证据、验收代码或实际输出变化后，必须重新全量验证。
